## Description
The compiler has the right major representations, but four claimed boundaries
are not yet closed by their owning modules. CPS Core is represented only as an
ordinary verified Buslane program; optional representation specialization is
interleaved with physical emission; compiler-produced WebAssembly is persisted
before target validation; and the documented WASI-only host contract conflicts
with required Lane runtime imports and named control exports.

These are ownership and phase-contract defects rather than a reason to merge
Buslane, Runtime ANF, VM CFG, ARC-final VM CFG, Physical Program, or Wasm. Each
of those representations owns a distinct necessary invariant and remains in
scope as an independent boundary.

## Design
Close each missing contract at its natural owner:

- effect lowering produces an opaque certified CPS Core value;
- representation specialization is planned completely before physical
  emission and remains removable from generic lowering;
- the Wasm target certifies the exact bytes it returns as an artifact; and
- the implementation and documentation agree on one truthful WebAssembly host
  contract.

Do not add parallel ASTs, fallback paths, heuristic specialization limits, or
consumer-side reconstruction of producer facts.
