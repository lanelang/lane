## Description
Implement the RFC's Runtime Array Object, descriptor-directed element
ownership, bounds checks, destruction, and pure copy-on-write update in the
sole Wasm target.

## Design
Use one ARC object with the portable header, stored element layout identity,
and contiguous erased I64 slots. Emit only reachable typed runtime helpers.
Array operations consume the verified Physical contract and validate object
layout and companion agreement defensively; they never select representation
from source types. The same emitted bytes run under both Wasmoon modes.

## Acceptance Criteria
- [x] Empty, Make, Length, Get, and Set implement the RFC object layout and
      checked size/index arithmetic.
- [x] Get establishes an independent owner and destruction releases every
      element exactly once.
- [x] Set reuses a unique owner and copies a shared owner without changing any
      observable alias.
- [x] Zero-length owned fills, allocation failure, and partial initialization
      preserve exact ownership.
- [x] Invalid layout identities, non-Array objects, and companion mismatches
      fail safely without publishing a partial owner.
- [x] Wasmoon interpreter and JIT pass the same semantic and ownership corpus.
