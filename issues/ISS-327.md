## Description
`CheckedInitializationOrder` and `CheckedSourceFile::initialization_order` are
part of the generated public interface, but the only consumer is the same
file's `in_initialization_order` operation. The public API exposes an
intermediate planning representation with no external use.

## Design
Keep the order enum and raw computation private to the checked package. Preserve
the public reordering entry and public cycle-member payload required by the
module compiler.

## Acceptance Criteria
- [x] The raw order enum is absent from the generated package interface.
- [x] The raw `initialization_order` method is absent from the generated package interface.
- [x] `in_initialization_order` and its diagnostic payload remain public.
- [x] Initialization-order tests remain unchanged and green.

## Close Notes
`CheckedInitializationOrder` is now private and the raw
`CheckedSourceFile::initialization_order` method is package-local. Its unused
debug and equality derivations were removed with the public surface.

`CheckedSourceFile::in_initialization_order` and
`CheckedInitializationCycleMember` remain public for the module compiler. The
generated interface diff contains exactly the two intended removals.

Verified with `moon check --target native --warn-list +73`, the two
initialization-filtered compile tests, `moon info`, and `moon fmt`.
