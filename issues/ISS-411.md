## Description
Known constructors still survive as heap aggregates through Runtime ANF and
Physical Lowering even when every use is a local projection, constructor match,
or reconstruction. The generated `make_data`, field projections, consume
operations and ARC traffic then expand substantially in Wasm.

## Design
Perform scalar replacement at the earliest verified IR that owns complete use
and evaluation-order facts. Reuse ISS-410 static summaries and the existing
Core use analysis. Replace an aggregate with ordered field bindings only when
all uses are understood, the value does not escape or require object identity,
and payload ownership/effects are preserved exactly.

Do not introduce a second escape-analysis sidecar, specialize nominal storage,
or recover source constructors from Physical instructions. Unsupported use
forms simply retain the aggregate; this is the optimization's proof boundary,
not a representation fallback.

## Acceptance Criteria
- [ ] Local known construct/project/match chains avoid aggregate allocation.
- [ ] Effectful payloads retain source evaluation order and exactly-once
      execution.
- [ ] Escaping, recursive, identity-observable, open-layout and unsupported
      aggregates retain ordinary allocation.
- [ ] Removed aggregates also remove their projections and associated ARC work
      before Physical emission.
- [ ] Black-box behavior tests cover positive and negative cases; private
      ownership/use invariants use only necessary white-box tests.
- [ ] Explore shows a strict structural reduction on at least one pinned real
      program without making the measured value an optimization threshold.
