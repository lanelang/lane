# ISS-421: Publish the Array withdrawal atomically

## Description
Lane currently pins Basic commit `b4b95e1`, but that commit exists only in the
local Basic repository. Publishing Lane before Basic would leave the gitlink
unfetchable and break clean checkout and CI.

## Design
Verify both repositories are clean, push Basic first, confirm the pinned commit
is reachable from the Basic remote, then push Lane and confirm its branch and
gitlink are reachable. Do not rewrite either branch or substitute a different
Basic revision.

## Acceptance Criteria
- [ ] Basic commit `b4b95e1` is reachable from the configured Basic remote.
- [ ] Lane's committed gitlink names that exact reachable commit.
- [ ] The Lane branch containing the Array withdrawal is pushed after Basic.
- [ ] Both local repositories remain clean.
