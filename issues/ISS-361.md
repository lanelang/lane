## Description
Compose stage metrics and transformation-owned function provenance into the
public Explore report, JSON response, and native HTML viewer. Document the
stability contract and finish repository-wide validation.

## Design
Explore schema v2 adds metrics to completed snapshots and a report-level
function provenance graph. Graph identities are structural stage-local IDs;
edges are explicit. JSON and HTML presentation consume those fields directly.
A new ADR extends ADR-0115 and records why observations remain sidecars rather
than persisted IR fields.

## Acceptance Criteria
- [x] Explore report schema version is 2 while entry discovery remains version 1.
- [x] JSON exposes ordered metrics and a complete structured provenance graph.
- [x] Native HTML shows per-stage metrics and source/synthetic function lineage.
- [x] Presentation contains no label, span, text, or ID-offset inference.
- [x] A black-box request traces a named function through ANF, VM CFG, bytecode,
      and Wasm and covers a synthetic function.
- [x] The ADR and optimization priority document describe the delivered model.
- [x] `moon info`, `moon fmt`, `moon test --target native`, and
      `tools/check-lane-integration.sh` pass.
