# ISS-331: Preserve normalization diagnostics at distinct verifier paths

## Description
The Buslane verifier deduplicates `TypeNormalizationFailure` diagnostics by
kind alone. When the same bounded normalization failure occurs at two distinct
metadata or expression paths, the later diagnostic is silently discarded and
its provenance is lost.

## Design
Treat a normalization diagnostic's identity as its kind together with the
current structural provenance. Preserve the existing suppression of repeated
recovery attempts at one path, but report the same failure independently when
it originates from another path.

## Acceptance Criteria
- [x] Equal normalization failures at distinct provenance paths are both reported.
- [x] Repeated recovery at the same provenance path remains deduplicated.
- [x] A black-box structured test observes the complete diagnostics for two independent bad top-level initializers.
- [x] `moon test --target native`, `moon info`, and `moon fmt` pass.

## Close Notes
Normalization diagnostic deduplication now uses `(kind, provenance)` rather
than `kind` alone. The regression verifies that two value initializers checked
against the same runaway beta term each retain their own top-level value anchor
while repeated recovery at one structural path remains collapsed.
