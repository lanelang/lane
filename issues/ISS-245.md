## Description
Teach the concrete syntax and module frontend to represent
`import module.path as Alias` without changing the canonical dependency path.

## Design
Reserve `as` globally. Preserve the alias name and precise source span in the
syntax AST while keeping the imported canonical ModulePath explicit. Format
the `import`, module path, `as`, and alias token chain through trivia-aware
boundaries. Module headers and graph edges continue to use only the canonical
target path.

## Acceptance Criteria
- [x] Lexer and parser accept `import Basic.Data.List as List` and reject aliases on open/selective imports.
- [x] Alias is exactly one identifier and `as` is a reserved keyword.
- [x] Syntax AST stores alias spelling and span without constructing invalid empty names.
- [x] Formatter preserves comments at module-path/`as`/alias boundaries and is idempotent.
- [x] Module header and graph dependency extraction ignore the local alias and retain the canonical path.
- [x] Parser, formatter, and module-frontend regressions pass.
