## Description
Explore snapshots contain only rendered text and diagnostics, so program growth
between stages cannot be measured without ad-hoc text parsing. Define stable,
typed scale metrics and collect them directly from each observed IR.

## Design
The Explore protocol owns a closed metric vocabulary and deterministic ordering.
Collectors use exhaustive typed-IR traversal and never parse pretty output.
Metrics describe structural counts only; timings and other environment-dependent
measurements are excluded. Stage families emit fixed metric sets including zero
values so reports are directly comparable.

## Acceptance Criteria
- [x] Explore snapshots carry an ordered array of typed metrics.
- [x] Buslane, effect-lowering, ANF, VM CFG, bytecode, and Wasm observations have
      useful structural and representation-cost metrics.
- [x] Per-function size facts exist for stages where functions are explicit.
- [x] Repeated exploration of one request produces equal metric values and order.
- [x] Metric tests use typed values and do not search rendered stage text.
