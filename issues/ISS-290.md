# ISS-290: Infer callback effects through nominal constructor payloads

## Metadata
- Type: bug
- Status: closed

- Assignee: unassigned
- Created: 2026-08-01
- Updated: 2026-08-02
- External ref: modules/lanec/typecheck/generic_arguments.mbt

## Description
A generic call cannot infer an effect parameter when its adjacent argument is a
nominal construction containing an unannotated function literal. For example,
`run_all[E](List[() -> Unit ! E])` rejects
`run_all([fn() { () }])` with E3010, while `run_all[{}](...)` succeeds.

The original report was closed after testing only direct callback arguments.
Those shapes infer correctly, but they do not exercise the nominal constructor
that prevents the whole argument from synthesizing before effect collection.

## Design
Keep ordinary type inference unchanged. After ordinary argument and expected
result constraints are collected, recursively measure only ground function
literals reached through resolved nominal variant payloads. Record their latent
effects through the existing function-effect upper-bound path. Do not infer
callback parameter/result types, hidden variant witnesses, nominal variance, or
delayed constraints.

## Acceptance Criteria
- [x] Pure function literals inside List sugar infer the empty effect.
- [x] Effectful literals inside List sugar infer their latent effect, and
      repeated literals join lower bounds canonically.
- [x] An unground callback parameter/result shape still reports E3010.
- [x] Typechecking judgments document the bounded nominal-payload evidence walk.
- [x] Native typecheck, compile, and full repository tests pass.

## Close Notes
Added a bounded latent-effect evidence walk for function literals reached through
resolved nominal variant payloads. It reuses existing ground-shape measurement
and function-effect upper-bound collection without adding ordinary type evidence,
hidden witness inference, nominal variance, or delayed constraints.

Compiler-facade regressions cover empty, single-effect, and joined-effect List
literals plus the unground callback-shape E3010 case. Updated ADR-0120 and the
typechecking judgments. Verified with `moon test modules/lanec/typecheck --target
native` (246/246), `moon test modules/lanec/compile --target native` (177/177),
`moon check --target native --warn-list +73 --diagnostic-limit 200`, and `moon
test --target native` (1363/1363).
