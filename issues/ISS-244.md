## Description
Record the accepted language and architecture contract for
`import module.path as Alias` so implementation and future maintenance do not
reintroduce ambiguity between canonical module identity and local qualifier
names.

## Design
Document alias replacement rather than addition, single-identifier aliases,
qualified-import-only syntax, canonical post-resolution identity, source-level
binder navigation, fixed sugar provider availability, use accounting, and the
absence of module hierarchy. Supersede the part of ADR 0119 that treats
compiler-generated canonical targets as indistinguishable authored qualified
names before resolution.

## Acceptance Criteria
- [x] Root glossary terms and rules reflect the accepted alias semantics.
- [x] The language-surface context describes canonical sugar availability through aliases.
- [x] A new ADR records the canonical imported module / lexical module binding split.
- [x] ADR 0119 no longer claims that generated canonical targets use authored lexical module lookup.
- [x] Documentation contains no claim that Lane has parent, child, or submodules.
