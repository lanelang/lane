# ISS-400: Remove the legacy semantic host-runtime stack

## Description
WebAssembly is Lane's sole executable target, but the execution path still
retains the semantic host-runtime architecture created for an independent
LoisVM interpreter: `RuntimeValueKind`, `RuntimeRegistry`, semantic Runtime
Imports, the Opaque Host Object Table, runtime-service exports, a duplicated
runtime-import manifest, and a linked container around the emitted Wasm bytes.
The Wasm module and this semantic protocol both produce linkage facts.

Complete the accepted WASI Preview 1 WebAssembly Target RFC by replacing this
stack, not by adding another compatibility adapter. Target-independent semantic
IR, VM CFG, ARC-final/physical-slot planning, the verified Wasm Physical
Program, and Wasm emission remain distinct because they own different
invariants.

## Design
Use the standard core-Wasm import/export contract as the sole executable ABI.
The canonical WASI Preview 1 catalog owns standardized imports. Raw source
externs name a module and field and are restricted to mechanically lowered
core-Wasm values. Basic implements console output above the narrow guest-memory
WASI seam. The compiler emits `_start` and `memory`, then deletes every semantic
manifest, registry, host-object, and `lane.runtime.v1` path. The linked
executable is the raw `.wasm` module.

Each child issue must replace an existing fact owner and delete the superseded
path in the same completed migration. No fallback, target switch, or duplicate
manifest is retained.

## Acceptance Criteria
- [x] Standard core-Wasm imports and exports are the only executable ABI facts.
- [x] Basic console output and the command lifecycle use WASI Preview 1.
- [x] Runtime Registry, Runtime Value Kind, semantic Runtime Import manifest,
      Opaque Host Object Table, and runtime-service exports are deleted.
- [x] `lane link` emits raw `.wasm`; `lane exec` consumes raw `.wasm`.
- [x] No `lane.runtime.v1`, `lane.entry`, or `lane.memory` public ABI remains.
- [x] Wasmoon interpreter and JIT execute identical emitted bytes.
- [x] Native tests, valid examples, and the pinned Basic suite pass.

## Close Notes

Closed on 2026-08-28 after ISS-401 through ISS-406 replaced every legacy fact
owner rather than layering a compatibility path. Raw standard WebAssembly is
the executable; its import/export sections are authoritative, WASI Preview 1
owns system linkage, and Wasmoon interpreter/JIT are execution strategies for
the same bytes. The semantic host registry, manifest, host objects, runtime
services, and linked executable container are deleted.
