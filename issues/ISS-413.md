## Description
The post-ISS-411 Basic image still contains 327 Canonical Generic ABI erasures
and 146 unerasures. Wasm emission attributes 2,659 instructions to erasure.
These counts do not prove that every bridge is redundant, but they identify a
remaining representation boundary whose payload and layout witness are still
propagated as separable facts.

## Design
Represent an erased payload and its layout witness as one VM CFG value fact.
The existing representation and ownership contracts remain authoritative;
propagation may reuse a witness or cancel an inverse erase/unerase pair only
when the complete paired fact proves that payload representation, witness,
cleanup, and ownership all agree.

The optimization belongs before ARC finalization and physical-slot emission.
Physical Lowering may produce the pair, and VM CFG simplification may consume
it, but the Wasm backend must not reconstruct the relation from neighboring
instructions. Open generic boundaries, storage crossings, incompatible cleanup
contracts, and escaping values retain the canonical generic ABI operations.

Do not specialize nominal storage, infer a witness from a source type, split
the ownership proof from the witness, or use bridge counts as a semantic
threshold.

## Acceptance Criteria
- [ ] VM CFG has one structured fact for an erased payload and its layout
      witness, including representation and ownership provenance.
- [ ] Locally inverse erase/unerase pairs are removed only when the complete
      paired contracts agree.
- [ ] Repeated constant witnesses are reused without changing evaluation or
      ownership order.
- [ ] Open generic, stored, escaping, and cleanup-incompatible values retain
      their required bridges.
- [ ] Explore reports the owner-produced bridge and Wasm erasure deltas on the
      pinned Basic entry.
- [ ] JIT and `--no-jit` agree; native tests and all valid examples pass.
