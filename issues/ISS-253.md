## Description
Implement the closed S32, Char, UTF-8, and ByteSequence intrinsic contract through checked lowering, Buslane, codecs, module artifacts, and linked artifacts.

## Design
Preserve semantic type identity through Buslane. Erase only the closed representation-identical conversions during intrinsic lowering and use explicit S32/Int width conversions.

## Acceptance Criteria
- [x] Every ADR intrinsic has exactly one accepted name and signature, and `%string_equal` is removed.
- [x] Buslane types, literals, equality, substitution, display, text, and codec cover S32 and Char.
- [x] Buslane codec and affected artifact schemas advance exactly as specified and reject old versions.
- [x] Focused ABI, Buslane, compile, and codec tests pass.
