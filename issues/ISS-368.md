## Description
The Coroutine Scheduler grows substantially across selective CPS and runtime
representation lowering. Some closures and indirect calls are intrinsic to
escaping continuations, but generic boundaries also retain avoidable callable
adaptations and erase/unerase operations.

Earlier work attempted to prove every remaining physical representation with a
whole-program plan and then reduce the resulting adapters. That architecture
made the optimization part of correctness and is superseded by ADR-0138.

## Design
First complete ISS-390 so the Scheduler lowers correctly through the Canonical
Generic ABI with specialization disabled. Then use the optional program rewrite
from ISS-363 and the structural callable adaptation seam from ISS-378 to remove
only operations whose complete producer and consumer contracts prove them
redundant.

Classify remaining generated functions and adaptations by observable cause:

- source-semantic escaping continuation;
- canonical generic ABI boundary;
- optional closed representation worker;
- first-class callable adaptation; or
- downstream devirtualization opportunity.

Do not introduce another demand graph, representation solution, specialized
nominal family, recipe sidecar, name-based recognizer, or size/frequency
heuristic. Generic lowering is the baseline; optimizations rewrite actual
program structure and ordinary cleanup removes dead artifacts.

## Acceptance Criteria
- [x] The Scheduler passes under JIT and `--no-jit` with representation
      specialization disabled.
- [x] Explore attributes every remaining adapter and erase/unerase operation to
      generic ABI, explicit structural adaptation, or source-semantic escape.
- [x] Equal complete producer/consumer contracts contain no adapter or
      erase/unerase operation.
- [x] Escaping continuations retain every adaptation required by a real ABI
      difference.
- [x] Optional specialization and devirtualization strictly reduce at least one
      lowering metric without increasing another stage merely to hide the cost.
- [x] No consumer-visible representation plan or specialized data-family model
      is introduced.
- [x] The Scheduler prints `1112211322` under JIT and `--no-jit`.
- [x] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`,
      `moon test --target native`, and the valid examples gate pass.

## Close Notes
Explore Report Protocol v11 now names erasure metrics
`genericAbiEraseCount`/`genericAbiUneraseCount`, presents callable workers as
structural callable adapters, and retains callable-flow boundaries for each
remaining indirect call. The real Scheduler regression joins these owner-
produced facts instead of inferring from rendered names: its 21 adapter workers
have 26 materializations, 20 adapter targets cross aggregate storage, one
adapter is direct-only after callable-flow analysis, and its 15 erasures plus
11 unerasures are Canonical Generic ABI crossings. The direct-only continuation
materialization is part of the broader pre-closure contification work deferred
under ISS-392.

The existing complete-contract tests continue to prove identity adaptation is
absent and unequal callable results retain a structural adapter. Closed generic
specialization still removes the focused fixture's layout and representation
bridges while the independently executable generic fallback remains available;
VM CFG callable-flow reduces the Scheduler's indirect calls to 44 without a
speculative dispatch path.

With representation specialization temporarily disabled at its private owner
boundary, the real Scheduler printed `1112211322` under both Wasm JIT and
`--no-jit`; the production configuration produced the same results. Final
verification ran `moon info`, `moon fmt`, strict native check, all 1,721 native
tests, the seven Lane Wasm protocol tests, and the valid examples gate.
