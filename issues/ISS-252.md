# ISS-252: Implement Char and Unicode literal decoding

## Metadata
- Type: feature
- Status: closed
- Priority: 1
- Labels: lexer, parser, formatter, unicode, agent
- Assignee: codex
- Created: 2026-07-30
- Updated: 2026-07-30
- External ref: ADR-0124

## Description
Add the Char primitive on the established I32 path, upgrade String literals to decoded UTF-8 scalar sequences, implement the accepted Char and Unicode escape grammar, remove `\xNN`, and make formatter output canonical and idempotent.

## Design
Use one literal decoder for String and Char. Store decoded semantic values and render direct Unicode plus the canonical short and `\u{HEX}` escapes from ADR 0124.

## Acceptance Criteria
- [x] Direct multibyte UTF-8 and every accepted escape parse and format idempotently.
- [x] Invalid Unicode, surrogate, malformed escape, empty Char, and multi-scalar Char cases produce precise diagnostics.
- [x] Removed `\xNN` input is rejected.
- [x] Lexer, parser, and formatter focused tests pass.
