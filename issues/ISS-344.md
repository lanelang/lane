# ISS-344: Give finalized callable ABIs one owner

## Description
VM CFG finalization interns callee callable ABIs before `finalize_body` performs
ownership and slot transformations. Indirect call sites then reconstruct a
separate ABI from the transformed local metadata. The two producers can observe
different cleanup shapes, as previously happened when valid examples exposed
`Trivial` versus `OwnedRef` argument mismatches.

## Design
Derive callee and call-site ABIs from one canonical finalized-slot model owned by
the finalizer. Do not snapshot callee metadata before transformations or repair
individual mismatches in the verifier. Runtime-import ABIs must enter the same
interning plan without becoming dependent on VM CFG internals.

## Acceptance Criteria
- [ ] No callable ABI is interned from pre-finalization ownership metadata.
- [ ] Callee definitions, direct calls, indirect calls, tail calls, and runtime
      imports consume one canonical ABI-construction operation.
- [ ] Borrowed source values that become trivial bytecode slots produce the same
      cleanup shape at definitions and every call site.
- [ ] Focused regressions cover owned, borrowed, erased, and higher-kinded
      callable arguments and results.
- [ ] All valid examples, interpreter/JIT conformance, `moon test --target
      native`, and `git diff --check` pass.
