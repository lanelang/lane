## Description
The post-ISS-411 Basic image still contains 327 Canonical Generic ABI erasures
and 146 unerasures. Wasm emission attributes 2,659 instructions to erasure.
These counts do not prove that every bridge is redundant, but they identify a
remaining representation boundary whose payload and layout witness are still
propagated as separable facts.

## Design
First establish whether the aggregate bridge count contains a local
optimization opportunity. The existing VM CFG metadata already binds every
erased payload to its layout witness, while erasure instructions and ARC plans
own representation and ownership transfer. A new propagation seam is justified
only if the pinned programs contain locally inverse bridges or repeated static
witnesses that this complete contract can remove.

If the remaining bridges instead cross calls, aggregate storage, dynamic
callables, or open generic boundaries, close the task without adding a pass.
Those boundaries are the canonical generic ABI, not local redundancy. Do not
retain an optimization that only changes a synthetic white-box fixture.

## Acceptance Criteria
- [x] The VM CFG value, use-definition, ARC, and Wasm ownership boundaries are
      audited before introducing a new fact or rewrite.
- [x] Pinned Basic and coroutine-scheduler Explore reports are compared through
      owner-produced bridge, slot, local, and Wasm-erasure metrics.
- [x] The comparison establishes whether locally inverse bridges or repeated
      static witnesses exist in either pinned program.
- [x] No production pass is retained when it produces no structural delta on
      either pinned program.
- [x] Native tests remain green after the investigation is removed.

## Close Notes

- 2026-08-28: The audit found that `ValueMetadata.erased_companion` already
  binds an erased payload to its witness, erasure instructions own the
  representation transfer, and ARC owns the consuming ownership transfer. A
  temporary complete-contract local rewrite and witness reuse experiment
  changed a synthetic VM CFG fixture but changed neither pinned Basic nor the
  coroutine scheduler.
- Basic remained at 327 erasures, 146 unerasures, 4,030 Physical slots, 4,782
  Wasm locals, and 2,659 erasure-attributed Wasm instructions. The scheduler
  remained at 15 erasures, 11 unerasures, 414 Physical slots, 480 Wasm locals,
  and 164 erasure-attributed Wasm instructions.
- The residual bridges cross generic calls, aggregate or callable boundaries;
  their removal belongs to closed-ABI specialization, not a local VM CFG
  peephole. The experimental pass added substantial mechanism with zero pinned
  structural benefit, so it was deleted rather than committed.
