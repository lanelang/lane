## Description
Make demand planning cover local generic definitions, local recursive groups,
and forwarding cycles without relying on a mutable rewrite scope to discover
instances while lowering bodies.

## Design
Give every definition a stable lexical site and carry the ambient canonical
effect environment in concrete demand keys. A recursive group is scheduled to
a fixed point before any member body is rewritten.

## Acceptance Criteria
- [x] Local generic definitions can be retained, specialized, or both.
- [x] Self recursion and mutually recursive forwarding terminate deterministically.
- [x] Nested scopes cannot resolve a definition from the wrong lexical owner.
- [x] White-box tests cover local definitions and an SCC.
