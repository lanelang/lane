# ISS-403: Delete the semantic Lane host runtime

## Description
After source externs and Basic I/O use core-Wasm/WASI contracts, the Runtime
Registry, Runtime Value Kind, semantic Runtime Import manifest, Opaque Host
Object Table, and runtime-service capability exports have no consumer.

## Design
Delete the obsolete types, packages, loader adapters, tests, diagnostics, and
glossary entries. Wasmoon loading supplies the standard WASI Preview 1 host and
validates the emitted module. Preserve compiler-owned linear-memory allocation,
ARC, fatal cleanup, and deterministic float formatting; these are Wasm target
implementation facts rather than a semantic host registry.

## Acceptance Criteria
- [x] No Runtime Registry, Runtime Value Kind, semantic Runtime Import, Opaque
      Host Object Table, or runtime-service export remains.
- [x] No `lane.runtime.v1` import or private semantic binding path remains.
- [x] Wasmoon interpreter and JIT load the same standard module contract.
- [x] Removed public interfaces disappear from generated `.mbti` files.

## Close Notes

Closed on 2026-08-28. Deleted the semantic runtime registry, bindings, value
kinds, host-object stores, runtime services, manifest resolution, and adapter
tests. `lane_runtime/wasm` now validates raw Wasm, registers WASI, and accepts an
optional Wasmoon Linker configuration for direct core imports. Deterministic
float formatting and fatal control remain a narrow compiler-private internal
ABI. Generated interfaces contain none of the removed public types.
