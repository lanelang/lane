## Description
Expose the raw Array intrinsics through Basic.Builtins, provide the safe
Basic.Data.Array policy layer, and certify the complete source-to-Wasm feature.

## Design
Basic owns checked OutOfBound behavior and ordinary algorithms; it does not own
the primitive Array identity or become a compiler-recognized provider. Tooling
consumes the compiler-owned type identity. Public examples and Basic tests
observe pure values and diagnostics rather than allocation identity.

## Acceptance Criteria
- [ ] Basic.Builtins exposes the five canonical bindings and Basic.Data.Array
      exposes checked empty, make, length, get, and set.
- [ ] Public tests cover scalar, reference, callable, nominal, nested, generic,
      uninhabited, alias-preserving, and first-class builtin cases.
- [ ] Checked invalid operands report OutOfBound before primitive invocation.
- [ ] Hover, completion, inlay, and semantic indexing present `Array[T]`.
- [ ] Valid and invalid examples cover the complete public contract.
- [ ] Native tests, all valid examples, pinned Basic, and both Wasmoon modes
      pass; ISS-296 acceptance criteria are closed with measured evidence.
