## Description
`diagnostic_architecture_wbtest.mbt` reads source files, searches for hard-coded
filenames and string markers, scans upward through candidate project roots, and
contains its own path helpers. It can fail after a harmless file move and can
pass while diagnostic ownership is semantically broken. It also adds filesystem
and environment dependencies to compiler facade tests.

## Design
Delete the test rather than extending its marker list or path discovery.
Enforce diagnostic ownership through package dependency direction, private
phase-local diagnostic types, generated interfaces, and behavior-oriented
golden tests. Remove filesystem/environment test dependencies made unused by
the deletion.

## Acceptance Criteria
- [x] `diagnostic_architecture_wbtest.mbt` is deleted in full.
- [x] No replacement test scans implementation source text, filenames, or comment/string markers.
- [x] Filesystem and environment dependencies used only by that test are removed.
- [x] Existing diagnostic golden tests still cover parser, resolve, typecheck, compile, link, and artifact behavior.
- [x] Package interfaces and dependency direction prevent compile orchestration from owning phase-specific diagnostic variants.
- [x] `moon info`, `moon fmt`, focused tests, `moon test --target native`, examples, and `git diff --check` pass.
