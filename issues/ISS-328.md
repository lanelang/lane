## Description
`CheckedInitializationGraph` stores node symbols, references, and initialized
membership in three parallel arrays. Traversal searches one array for an index,
uses that index in another, and separately searches a third collection to
recover one node's facts.

## Design
Introduce one private initialization node containing its symbol, references,
and initialized flag. Keep the temporary symbol list used to collect lexical
references out of the retained graph representation.

## Acceptance Criteria
- [x] Each retained graph node owns its symbol, references, and initialized flag.
- [x] Traversal no longer correlates parallel arrays by index.
- [x] Initialization ordering and cycle diagnostics are unchanged.
- [x] No public interface changes.
