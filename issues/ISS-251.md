# ISS-251: Add S32 and Char to the semantic frontend

## Description
Add the `S32` and `Char` primitive types, expected-type-directed S32 integer literals, Char literals and patterns, checked values, type display, and semantic tooling representation.

## Design
Keep S32, Char, Int, and Byte definitionally distinct. S32 integer literals use an S32 expectation and otherwise default to Int. Char literals decode to exactly one Unicode scalar.

## Acceptance Criteria
- [ ] Syntax, resolve, desugar, checked AST, types, and analysis represent S32 and Char structurally.
- [ ] S32 literal expressions and patterns cover both signed bounds and reject out-of-range values.
- [ ] Char expressions and patterns are type-distinct from String, Byte, S32, and Int.
- [ ] Focused frontend and semantic tests pass.
