## Description
Structural callable adaptation and closed representation workers now use
complete contracts locally, but the executable pipeline does not yet prove the
ISS-392 invariant that every definitionally equal complete runtime ABI shares
one implementation while every unequal first-class conversion has one explicit
reason.

## Design
After Runtime ANF owns callable disposition, intern the complete executable ABI
of direct and escaping implementations at the existing Physical Callable ABI
seam. Equal contracts share one worker, identity adaptations disappear, direct
conversions fuse into calls, and an escaping source/target pair materializes at
most one structural adapter. Preserve the generic fallback and finite recursive
specialization demand set.

The key includes every evidence, capture, value parameter and result contract,
including representation, cleanup, semantic runtime category, object/callable
shape, witness provenance and result control. Source syntax, names, widths or
layout IDs alone are not keys.

## Acceptance Criteria
- [ ] Equal complete runtime ABIs share one implementation worker.
- [ ] Identity adaptations emit no bridge, environment or worker.
- [ ] Each remaining escaping adapter has one structured unequal-contract reason.
- [ ] Direct conversions are fused without first-class materialization.
- [ ] Open generic fallbacks remain executable and recursive demand is finite.
- [ ] Explore reports zero duplicate complete-ABI workers.
- [ ] Native tests, valid examples and Basic tests pass under JIT and `--no-jit`.
