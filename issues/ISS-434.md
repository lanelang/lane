## Description
Explore of the complete Basic test entry shows missed getter/projection
optimizations and candidate savings in callable ABI round trips through generic
storage and closure environments containing only static function identities.
Expanding these operations in Wasm compounds their cost. Generic callable
adaptation is not inherently redundant; ISS-435 must prove which compositions
can disappear while preserving shared generic consumers. Attributing the
artifact primarily to instruction selection was premature; instruction counts
alone do not establish that diagnosis.

The baseline is Lane `a965700571015db4200c9942d2da6a14e4749ac0` and Basic
`47762c5435d4058fc58f96f277d2eb7c325377cb`. Reproduce after building the release
CLI, with these revisions available, from the Lane repository:

```sh
_build/native/release/build/Milky2018/lane/lane.exe explore \
  ../basic/test/entry.lane:test_entry --lib-dir ../basic --no-basic \
  -o /tmp/lane-basic-explore.html
```

The inspected `../basic/basic.wasm` is 164,831 bytes. Its Code section is
149,691 bytes: 148,644 function-body bytes and 1,047 bytes of section payload
framing. Associating binary bodies with Explore's producer-owned lineage gives:

| Body category | Bytes |
| --- | ---: |
| Physical implementations other than structural adapters | 121,790 |
| Structural callable adapters | 12,768 |
| Float formatting builtins | 9,219 |
| Other runtime, helpers, destructors, and boundary wrappers | 4,867 |

Adapter body bytes exclude adapter construction in callers. Physical has 611
functions, 597 environment constructions, 567 closure constructions, 493 erase
and 284 unerase operations. Wasm has 722 defined functions and 65,788 rendered
instructions. Object-operation expansion accounts for 26,551 instructions;
this is a cost location, not proof that every object operation is avoidable.

## Design
- Address each fact at its existing owner rather than adding a second analysis
  or repairing upstream representation problems in the Wasm emitter.
- Implement the independently proven getter and projection improvements first.
  The higher-priority callable ABI issue requires an explicit design review;
  priority does not authorize an unreviewed representation change.
- Preserve generic fallback, complete callable contracts, ownership, and source
  effect semantics. Do not erase genuine dynamic calls or assume every adapter
  is redundant.
- Preserve the canonical generic ABI while improving proven adaptation
  composition and deferred materialization in ISS-435. Assess remaining static
  environments afterward; implementation sharing and closure-value sharing
  are distinct.
- Re-measure residual backend expansion after upstream improvements. Do not
  prescribe stackification, outlining, new budgets, or a target line count in
  advance of evidence.
