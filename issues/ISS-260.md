## Description
Update the Basic repository from Int, S32, and Double to I64, I32, and F64, add the F32 module and offers, and expose the complete compiler-owned builtin surface through ordinary Lane declarations.

## Design
Rename modules, declaration prefixes, offers, conversions, and dependent APIs instead of retaining compatibility shims. Basic remains ordinary Lane code over the closed intrinsic table and must exercise both interpreter and JIT execution.

## Acceptance Criteria
- [ ] Basic contains coherent `Basic.Data.I64`, `Basic.Data.I32`, `Basic.Data.F64`, and `Basic.Data.F32` modules.
- [ ] Arithmetic, equality, comparison, constants, and explicit conversions are exposed through consistently named builtin declarations and offers.
- [ ] Every Basic source and test uses the new primitive names; old numeric module and declaration names are removed.
- [ ] Basic check and its JIT plus interpreter test gate pass against the new Lane compiler.
