## Description
Runtime ANF currently represents every nested function with the same
`AnfFunction` form. Physical Lowering must therefore begin closure conversion
before the program has stated whether the callable is a same-function join
point, a direct-only lifted function, or a genuinely escaping closure. VM CFG
callable-flow can later prove some direct targets, but by then environments,
closures, adapters and table eligibility have already been materialized.

## Design
Make Runtime ANF construction classify lexical callable SCCs from their exact
uses and store the result in the verified IR:

- saturated tail-only local calls become join points in the enclosing function;
- saturated direct-only calls become lifted direct functions whose captures are
  explicit physical inputs;
- storage, return, argument, aggregate, evidence-opaque, or otherwise
  first-class use makes the complete SCC escaping;
- recursive groups are classified together;
- top-level retained functions remain ordinary direct roots.

The Runtime ANF verifier owns the use contract and rejects first-class or
unsaturated use of join/direct-only callables. Physical Lowering consumes the
classification and never reruns escape analysis. Join points lower to local VM
CFG blocks. Direct-only functions are not table-addressable and receive no
closure environment. Escaping functions retain the existing closure semantics.

Do not classify by function origin, generated name, traversal order, call
count, or function size. Do not export an escape-analysis sidecar.

## Acceptance Criteria
- [x] Runtime ANF explicitly distinguishes top-level roots, join points,
      direct-only functions and escaping closures.
- [x] Classification is SCC-aware and uses exact saturated call, tail position
      and first-class escape facts.
- [x] The Runtime ANF verifier rejects first-class, unsaturated or out-of-scope
      use of a join point or direct-only callable.
- [x] Join points lower to local VM CFG control flow without a physical function,
      environment, closure, adapter or callable-table entry.
- [x] Direct-only functions pass captures explicitly and allocate no environment,
      closure, adapter or callable-table entry.
- [x] Escaping and reusable continuations preserve existing semantics.
- [x] Explore reports disposition and zero direct-only materializations.
- [x] Black-box execution covers nonrecursive, recursive, captured, tail and
      escaping callables; focused white-box tests cover the private SCC invariant.
- [x] JIT and `--no-jit`, native tests, valid examples and Basic tests pass.

## Close Notes

  verifies it before Physical Lowering. Tail-only recursive groups become local
  VM CFG blocks; direct-only functions receive captures as explicit inputs;
  only escaping functions retain closure environments and table-addressable
  values. Explore exposes the disposition on each ANF function.

  Basic's 12-entry suite, and JIT/`--no-jit` execution of examples 04 and 37.
