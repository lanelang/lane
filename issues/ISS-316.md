## Description
Originally filed as "five examples fail on a Basic parse error". Follow-up
measurement disproved that premise: the failure was transient. The gate
compiles examples against the LIVE working tree of the sibling Basic checkout,
and the run happened to catch `src/data/string.lane` mid-edit (a half-typed
signature rendered as `: I64` at 68:4; the parser expected a parameter start —
identifier, `offer`, `auto`). Basic's committed HEAD and its finished working
tree both parse; rerunning the gate afterwards exits 0 with all examples
passing.

Grammar confirmation that no parser work is owed: the surface grammar defines
`parameter : parameter_modifiers identifier ":" type`
(modules/lanec/parser/yacc_parser/parser.mbty:424), so the language has no
anonymous-parameter form and a bare `: I64` at parameter start is ill-formed
by definition. The expectation set in the diagnostic is exactly the legal
parameter starts, so the parser and its message were both correct.

The submodule policy is now decided, but the current gitlink is not reproducible.
Lane pins `098c30a`, which is absent from the declared Basic remote, while the
pinned checkout and the sibling Basic checkout contain two divergent sets of
recent changes. No single Basic revision contains the numeric suffix migration,
float string declarations, simplified recursive Debug implementation, and the
repaired test gate.

## Design
Reconcile the two Basic histories onto one canonical branch after ISS-260 has
made its execution gate complete. The resulting revision must be obtainable
from the URL recorded in `.gitmodules`; only then may Lane advance its gitlink.
The integration gate continues to reject missing, mismatched, or dirty fixture
state and never modifies the submodule itself.

## Acceptance Criteria
- [x] The chosen policy is recorded (in the runner or its docs) and the runner's output makes a Basic-side failure attributable to Basic state.
- [x] The gate runs only when Basic is initialized at the exact gitlink revision with a clean worktree.
- [x] Missing, mismatched, and dirty fixtures fail before the Lane build without modifying Basic.
- [x] One Basic revision contains every recent compiler-dependent Basic change and the complete gate from ISS-260.
- [ ] The revision is fetchable from the `.gitmodules` URL in a clean clone.
- [x] Lane pins that revision and the full integration gate passes from the pinned checkout.
