## Description
Add `F32` as a distinct IEEE 754 binary32 source primitive with complete compiler, artifact, VM, interpreter, Wasm, analysis, and diagnostic support.

## Design
Floating literals default to F64 and elaborate to F32 when the expected type is F32, rounding once to binary32. F32 receives the arithmetic, comparison, special-constant, and explicit width-conversion intrinsics needed by Basic. Binary schemas are versioned when new semantic cases or instructions enter persisted formats.

## Acceptance Criteria
- [ ] F32 resolves globally and remains definitionally distinct from I32 and F64.
- [ ] F32 literals, patterns, arithmetic, comparison, infinities, NaN, conversions, generics, and diagnostics have structural tests.
- [ ] Buslane, VM CFG, bytecode, interpreter, Wasm interpreter/JIT, layouts, erasure, artifacts, and inspection support F32.
- [ ] Semantic tokens, hover, completion, and type rendering identify F32 correctly.
- [ ] Persisted schemas are versioned and reject their immediately preceding versions where required.
- [ ] Focused tests and the native repository gate pass.
