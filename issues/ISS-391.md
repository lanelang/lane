## Description
Runtime ANF currently records an optional source value for each function. A
missing source means only that no top-level source binding owns the function;
it does not distinguish a source-written nested function from a function
introduced by handler elaboration, monadic lowering or selective CPS.

ISS-369 therefore reports the factual `Anonymous` origin instead of guessing a
CPS origin from missing metadata. Explore cannot yet separate source-semantic
callable escape from lowering-introduced callable flow.

## Design
The transformation that introduces a function owns its origin. Define a small,
closed function-origin vocabulary at the effect-lowering/Runtime ANF boundary
and preserve it through ANF simplification and physical function planning.
Source elaboration marks source-written top-level and nested functions;
effect-lowering stages mark the functions they introduce. Later stages only
copy the origin and may add structural roles such as Callable Adapter or
Representation Worker.

Do not infer origin from a missing source binding, generated names, spans,
function order or rendered IR. Origin is diagnostic and observational metadata;
it must not affect optimization legality or runtime semantics.

## Acceptance Criteria
- [ ] Every Runtime ANF function has an explicit source-written or
      lowering-introduced origin in addition to any source binding identity.
- [ ] Handler, monadic and selective-CPS introduced functions retain distinct
      typed origins through ANF simplification and Physical Program emission.
- [ ] Explore distinguishes source-written anonymous flow from CPS-introduced
      flow without using names, text or absence of source metadata.
- [ ] Existing callable-adapter, representation-worker, initializer and runtime
      support roles remain structural facts produced by their owning stages.
- [ ] Black-box Explore coverage includes one source nested function and one
      CPS-introduced continuation with stable, distinct origins.
- [ ] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`, and
      `moon test --target native` pass.
