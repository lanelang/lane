## Description
`rewrite_cps_source_metadata` commits a declaration's target type before body
lowering, but `commit_cps_binding_type` then synthesizes the lowered AST and
overwrites the same metadata. The declaration and implementation are therefore
competing owners of one type.

`ProgramDeclarations` also exposes only membership queries, forcing CPS and its
validator to scan entire metadata tables and maintain a second count-based view
of the same source boundary.

## Design
Commit each reachable declaration target once before lowering. After lowering,
synthesize the RHS only to check that its actual type is consumable as the
committed declaration type; a narrower residual effect is valid and must not be
rejected by equality.

Have `ProgramDeclarations` expose the collected value and data-constructor IDs
directly. CPS metadata rewriting and monadic-transform validation iterate those
IDs without separate counts or full registry scans.

## Acceptance Criteria
- [x] CPS declaration target types are committed once before body lowering.
- [x] Lowered RHS types are checked by directed consumability and never written
      back into declaration metadata.
- [x] `ProgramDeclarations` consumers iterate collected IDs without
      `CpsSourceCounts` or whole-table membership scans.
- [x] Focused tests cover an incompatible RHS, a compatible RHS with a narrower
      residual effect, and preservation of the committed declaration type in
      both cases.
- [x] `moon check`, focused CPS and executable tests, and
      `moon test --target native` pass.

## Close Notes
`rewrite_cps_source_metadata` is now the only writer of reachable declaration
target types. Binding lowering synthesizes each RHS and checks
`type_is_consumable_as(actual, expected)`; an incompatible pair raises the
structured `BindingTypeMismatch` error without changing metadata.
The positive test uses an actual `Function(..., Empty)` against a committed
`Function(..., Io)`, so strict equality and reversed consumability both fail the
regression.

`ProgramDeclarations` records stable, deduplicated value and data-constructor ID
arrays. CPS metadata rewriting and monadic-transform validation iterate those
arrays directly; `CpsSourceCounts` and the full-table membership scans are gone.
