## Description
Ensure that effect-indexed nominal data and hidden existential binders remain
closed after selective CPS. The historical implementation preserved their
source `Effect` identities, even though callable binders had already become a
higher-kinded companion plus residual. That exception required a parallel
source/companion table and became invalid after alpha-renaming.

## Design
Apply the same two-fact elaboration at every binding and application site.
Nominal parameters and existentials become explicit companion/residual pairs;
constructors and patterns consume those pairs. Remove the source-effect
substitution recovery and companion sidecar from LoisVM lowering. Runtime
evidence follows the resulting explicit parameter kinds.

## Acceptance Criteria
- [x] Callable, nominal, and existential effect binders share one companion plus residual elaboration.
- [x] Constructor applications and pattern binders expose the same ordered pair.
- [x] LoisVM receives no source-effect companion sidecar and reconstructs no source effect substitution.
- [x] Effect-indexed existential runtime evidence is derived from the explicit companion kind.
- [x] Effect-lowering and production backend tests cover the closed representation.

## Notes
- 2026-07-13: Production integration exposed this because the previous pure LoisVM path correctly stored zero witnesses for effect-kind existentials.
- 2026-08-12: Reopened after ISS-305 and the CPS optimization audit proved the
  nominal-data exception left source binders outside their lexical CPS scope.
  ADR-0137 supersedes the original preserve-and-erase design.

## Close Notes
The original 2026-07-13 repair restricted companion rewriting to callable
boundaries. The 2026-08-12 reopening replaced that exception with ADR-0137:
nominal and existential binders now use the same explicit companion/residual
pair as callables. Production lowering no longer receives a source/companion
sidecar. Focused CPS, LoisVM, and backend-conformance tests exercise the closed
representation, including effect-indexed existentials and nested forall
binders. The full native suite passed 1679/1679.
