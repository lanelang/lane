## Description
Give Array operations explicit VM CFG and Physical Program contracts and lower
both direct and first-class polymorphic intrinsics through ordinary runtime
evidence adaptation.

## Design
Add typed Empty, Make, Length, Get, and Set operations plus the Array layout
recipe. The verified Physical Program owns slot representation, ownership,
companion, use-definition, and layout-operand invariants. Materialized
polymorphic intrinsic values become witness-aware wrappers shared by complete
runtime ABI. Physical lowering may consume Runtime ANF evidence; it must not
reconstruct layouts from source types or intrinsic names after emission.

## Acceptance Criteria
- [x] VM CFG and Physical Program model all five operations and Array layout.
- [x] Use/definition, ARC, cloning, simplification, pretty, and verifiers consume
      the explicit operation contracts.
- [x] Empty receives an explicit layout operand; Make/Get/Set use and validate
      erased companions exactly as specified by the RFC.
- [x] Direct generic calls and first-class generic wrappers produce the same
      Physical operations and complete runtime ABI.
- [x] Malformed raw Physical Programs are rejected before Wasm emission.
