## Description
Runtime ANF does not yet enforce the independent invariant claimed by its name.
`RuntimeAnfProgram` is a shallow wrapper immediately unpacked into the same
public `AnfProgram` accepted by general Buslane-to-ANF lowering. That ANF still
contains `Perform` and `Handle` variants which LoisVM rejects as impossible,
plus generic binders and type applications whose variables no longer occur
after effect projection.

In the current Coroutine Scheduler report, selective CPS contains six type
parameters that appear only once, while Runtime ANF contains seventeen.
Projection preserves `TypeLambda` and `TypeApply`, maps function effects to
`Empty`, and maps every `EffectArgument` to `EffectArgument(Empty)` without
atomically removing vacuous binders and their application arguments.

## Design
Make `AnfProgram` mean one thing: runtime-projected, backend-lowerable ANF.
Package-controlled lowering from verified effect-aware CPS Core is its sole
constructor. Delete the shallow `RuntimeAnfProgram`/general-ANF split, the
public arbitrary Buslane-to-ANF entry, and effectful ANF variants and handlers
that cannot reach the backend. LoisVM consumes this nominal program directly
without unwrapping it to a weaker representation.

At the same construction seam, perform binder-identity-aware runtime generic
cleanup. Compute which binders occur in runtime-relevant parameter, result,
capture, layout, and witness positions, then remove every vacuous binder with
the corresponding argument at every application. Validate application arity
and weak-head-normalize types where lowering observes their outer constructor.

Treat higher-kinded companions and explicit layout witnesses as runtime uses.
Process recursive groups and mutually recursive applications as one verified
unit. Do not infer liveness from rendered text, binder names, effect syntax, or
occurrence count, and do not reinterpret `Empty` as unavailable effect
information.

## Acceptance Criteria
- [ ] Runtime ANF has one package-controlled construction seam from verified
      effect-aware CPS Core and LoisVM consumes that exact nominal value.
- [ ] `Perform`, `Handle`, operation alternatives, handler tables, and every
      downstream impossible-node rejection are removed from Runtime ANF.
- [ ] Runtime projection and cleanup remove every binder that has no
      runtime-relevant use and remove its application argument atomically.
- [ ] Surviving binder and argument order remains definitionally and
      representationally correct across nested `TypeLambda` and `TypeApply`.
- [ ] Higher-kinded companions, layout-constructor witnesses, existential
      evidence, and recursive generic groups are preserved when used.
- [ ] Every surviving type application is arity-correct and has a
      definitionally valid, weak-head-normalized runtime target shape.
- [ ] A focused black-box fixture demonstrates that effect-only generic
      parameters disappear from Runtime ANF and later lowering.
- [ ] The Coroutine Scheduler has no projection-created vacuous binder shells;
      Explore records the before/after binder and type-application counts.
- [ ] The effect-aware CPS Core observed before runtime projection is unchanged.
- [ ] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`, and
      `moon test --target native` pass.
