## Description
`EffectLoweringResult.program` is an ordinary `Buslane.VerifiedProgram`. The
generic Buslane verifier accepts `Perform`, `Handle`, and `Resume`, and cannot
certify the effect-lowering postconditions described as verified CPS Core.
Runtime ANF consequently still discovers residual handlers and operations at
its consumer boundary.

The current type proves Buslane well-formedness, not that effect lowering is
complete. A generic Buslane optimization can therefore return a valid
`VerifiedProgram` without preserving the stronger CPS Core contract.

## Design
Introduce an opaque `CpsCoreProgram` certificate over the existing Buslane
program representation; do not copy or fork the Buslane AST. Effect lowering is
the sole producer. Certification owns the CPS-specific postconditions in
addition to ordinary Buslane verification, including:

- no residual `Perform`, `Handle`, or `Resume` expression;
- no unresolved private effect-lowering form or open context;
- every source effect binder has been replaced by its explicit companion and
  residual representation, with no original binder escaping its source scope;
- function provenance covers every retained or cloned CPS function.

Expose a CPS-preserving core-optimization entry point that consumes and returns
the certificate. Runtime ANF must consume `CpsCoreProgram`, not an arbitrary
`VerifiedProgram`, and must not own fallback checks for missing effect lowering.

## Acceptance Criteria
- [ ] An opaque CPS Core certificate is the only public effect-lowering result.
- [ ] The certificate has a phase-specific verifier or construction proof that
      checks the complete CPS Core postcondition without duplicating Buslane
      type verification.
- [ ] Core optimization preserves and re-certifies CPS Core rather than
      returning an unqualified Buslane program.
- [ ] Runtime ANF accepts only certified CPS Core and no longer reports
      `ResidualPerform` or `ResidualHandle` as consumer-owned failures.
- [ ] White-box negative tests reject forged residual effect forms at the CPS
      boundary; black-box effect examples still compile and run.
- [ ] `moon info`, formatting, native checks, native tests, examples, and Basic
      integration pass.
