# ISS-330: Terminate canonical match alternatives

## Metadata

## Description
The Buslane text grammar leaves one shift-reduce choice to the parser
generator's default policy. Match alternatives have no separator, so after a
default arm whose body ends in a postfix expression, `()` can either call that
expression or begin the next unit-literal alternative. The default shift policy
silently chooses the call and can parse canonical text as a different AST.

## Design
Terminate every canonical match alternative with `;`, making the expression
boundary structural instead of dependent on whitespace or generator policy.
Keep the existing parenthesized-type grammar and extend its black-box test into
a deterministic matrix of valid arities and malformed group spellings because
the original review also questioned that public `Result` boundary.

## Acceptance Criteria
- [x] Generating the Buslane parser reports zero conflicts.
- [x] A default arm followed by a unit-literal arm round-trips as two alternatives.
- [x] Parenthesized singleton types and zero-, one-, and many-parameter function types retain their meanings.
- [x] Malformed parenthesized type inputs return `Err` through the public parser.
- [x] Native Buslane text tests pass.

## Close Notes

Canonical match alternatives now end in `;`. The writer and grammar share that
boundary, so an arm body cannot consume the following unit-literal pattern as a
postfix call. A two-arm black-box round-trip test pins the exact former conflict,
and the public type parser test now covers zero through three parameter arities
plus malformed parenthesis spellings.

Regenerating the parser reports zero conflicts. Verified with `moon test
modules/buslane/text --target native` (28/28) and `moon test modules/buslane
--target native` (88/88); the one Pretty snapshot changed only by the new
canonical terminator.
