## Description
Wasm lowering imports float formatting helpers from
`lane.runtime.internal.v1`, while the owning LoisVM context only documents
`lane.runtime.v1`. The namespace's owner, compatibility scope, and lifecycle
are therefore implicit in code.

## Design
Document the public registry ABI and compiler-private runtime ABI as distinct
namespaces. State who provides each namespace, which artifacts may depend on
it, how versions change, and why internal helpers are not user host imports.
Do not promote the internal namespace into a public extension API.

## Acceptance Criteria
- [x] The owning CONTEXT document defines `lane.runtime.internal.v1` and contrasts it with `lane.runtime.v1`.
- [x] Float formatting imports and their deterministic contract are documented.
- [x] ABI ownership, versioning, and compatibility expectations match the implementation.
- [x] No second vocabulary is introduced for the same boundary.

## Close Notes
The LoisVM context now names the compiler-private internal runtime ABI, assigns
it to Wasm lowering plus the loader, and explicitly excludes it from the host
Runtime Registry. It documents the two float formatter signatures, canonical
special values, signed zero, shortest round-trip finite formatting, `.0` for
integral values, and the namespace-major compatibility rule.
