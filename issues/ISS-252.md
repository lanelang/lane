# ISS-252: Implement Unicode literal decoding and formatting

## Metadata
- Type: feature
- Status: open
- Priority: 1
- Labels: lexer, parser, formatter, unicode, agent
- Assignee: unassigned
- Created: 2026-07-30
- Updated: 2026-07-30
- External ref: ADR-0124

## Description
Upgrade String literals to decoded UTF-8 scalar sequences, implement the accepted Char and Unicode escape grammar, remove `\xNN`, and make formatter output canonical and idempotent.

## Design
Use one literal decoder for String and Char. Store decoded semantic values and render direct Unicode plus the canonical short and `\u{HEX}` escapes from ADR 0124.

## Acceptance Criteria
- [ ] Direct multibyte UTF-8 and every accepted escape parse and format idempotently.
- [ ] Invalid Unicode, surrogate, malformed escape, empty Char, and multi-scalar Char cases produce precise diagnostics.
- [ ] Removed `\xNN` input is rejected.
- [ ] Lexer, parser, and formatter focused tests pass.
