## Description
Create one semantic seam that classifies a generic use as incomplete, concrete,
or symbolically forwarded only after applying the ambient substitution and
normalizing its effect arguments. The rewriter currently reaches this decision
through several local branches.

## Design
Represent the classified application as a private domain value containing the
resolved definition, retained ordinary arguments, and canonical effect
bindings. Do not include runtime layout or CPS companion decisions in this
source-level classifier.

## Acceptance Criteria
- [x] All callable specialization decisions consume one classified-use result.
- [x] Effect aliases and definitionally equal rows produce equal concrete keys.
- [x] Symbolic arguments remain symbolic after substitution when parameters remain.
- [x] Classification has complete structured white-box tests.

classification. Callable rewriting and symbolic forwarding-edge collection now
consume its `Incomplete`, `Symbolic`, or canonical `Concrete` mode instead of
independently inspecting effect arguments. `require_instance` receives an
already-classified concrete binding key.
