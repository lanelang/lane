# ISS-380: Remove redundant frontend and module product fields

## Description
Several in-memory compiler products carry copied facts with no independent
invariant. Compile facade and Module Frontend define identical `SourceInput`
records and copy between them. `ModuleObject` retains Checked Source even though
checked syntax is not part of a linkable implementation artifact. Module Graph,
checked/compiled module sets, and compiled-module-set artifacts propagate
`reachable_module_path_texts` even though root plus imports and the actual
module collection already determine the closure and the linker does not consume
the copied list. Module-object models repeatedly flatten Buslane metadata and
terms instead of composing one Buslane Program.

## Design
Use one source-identity/text value owned below compile facade and Module
Frontend. Move Checked Source onto `CompiledModule`, leaving `ModuleObject` as a
link-only implementation. Remove derived reachable-path arrays wherever no
persistence or consumer contract requires them. Compose in-memory module
objects from one Buslane Program instead of parallel metadata and term fields;
persisted framing may remain flat only where the codec format requires it.

## Acceptance Criteria
- [x] Compile facade, Module Frontend, and Semantic Workspace use one canonical
      source input type without a field-copy adapter.
- [x] Module Object contains no Checked Source or other source-analysis state.
- [x] Compiled Module owns the matching Checked Source, Module Interface, and
      linkable Module Object.
- [x] Redundant `reachable_module_path_texts` fields are removed; every needed
      closure or presentation list is derived from the graph/modules owner.
- [x] In-memory module implementation models compose one Buslane Program rather
      than independently copying metadata and terms.
- [x] Artifact compatibility is changed only where a removed persisted field
      actually requires a schema update; no compatibility fallback is added.
- [x] Black-box compile, interface compilation, object linking, and artifact
      round-trip tests pass without asserting removed storage layout.
- [x] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`, and
      `moon test --target native` pass.
