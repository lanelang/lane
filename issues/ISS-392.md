## Description
Lane still materializes too many generated continuations, closures, callable
adapters, runtime functions, and helper functions between effect lowering and
WebAssembly emission. Individual optimizations have improved exact callable
flow, structural adaptation, and Wasm expansion, but the lowering pipeline does
not yet enforce the stronger end-to-end invariant that only genuinely escaping
callables and transitively reachable backend support are materialized.

Complete one ordered lowering architecture inspired by the relevant strengths
of MoonBit and Koka:

1. perform contification before closure and adapter materialization;
2. repeatedly simplify and inline newly generated continuations immediately
   after effect lowering;
3. share implementations by complete canonical runtime ABI shape;
4. emit only transitively reachable Wasm runtime and helper functions.

This work is intentionally deferred. When activated, split it into dependency-
ordered child tasks without changing the semantic ownership described below.

## Design

### Post-effect Core optimization

Deepen the existing `lanec/core_opt` operation instead of creating a second
optimizer. After effect lowering, drive local effect-aware simplification,
exact callable-flow discovery, known-continuation application reduction,
inlining, CSE, and DCE through one structural worklist until no accepted rewrite
creates new work.

Legality comes from verified effect facts, exact use structure, stable call-site
identity, and recursive SCC analysis. Function origin is provenance only. Do
not use generated names, traversal order, call counts, function sizes, or magic
scores as semantic decisions, and do not clone any planned call site more than
once.

### Runtime ANF contification

Make Runtime ANF construction own the distinction among join points, direct
callables, and escaping closures before Physical Lowering can allocate an
environment, closure, or callable adapter:

- saturated tail-only lexical uses become join points;
- direct non-tail uses remain direct callables with captured values passed
  explicitly;
- values stored, returned, packed into data, or otherwise used first-class
  remain closures;
- recursive SCCs are classified as groups;
- escaping or reusable continuations retain ordinary closure semantics.

Encode this distinction in the Runtime ANF structure and verifier rather than
exporting a parallel escape-analysis sidecar. Physical Lowering must consume the
classification and must not rediscover whether a callable escapes.

### Canonical runtime ABI sharing

Deepen the existing structural adaptation and representation-specialization
seams so they consume interned complete runtime contracts. Callable invocation
identity covers every evidence, value-parameter and result contract, including
representation, cleanup and ownership, semantic runtime category, object or
callable shape, layout-witness provenance, and result control convention.
Closure environment shape belongs to the implementation rather than callable
compatibility.

Definitionally different source types with the same complete invocation
contract may share one worker only when they instantiate the same semantic
implementation with the same closed body-rewrite contract. ABI equality alone
never merges different function bodies. Equal source and target contracts
require no adapter. A direct conversion is fused into its call; an escaping
conversion materializes at most one worker for its canonical source/target and
parameter-alignment contract. Open generic fallback implementations remain
available. Machine width, layout ID, source name, or erased syntax alone is
never a sharing key.

### Reachable Wasm catalog

Keep `WasmFunctionCatalog` as the sole owner of Wasm function identity, table
slots, types, provenance, and emission order, but make it catalog only the
transitive closure required by the emitted program. Roots include the entry
wrapper, exports, reachable Physical functions and imports, callable-table
entries, global lifecycle, and persisted layout recipes. Shape support is
reachable only through a retained layout recipe; an object-shape metadata entry
is not independently a root. Physical operations, runtime functions, and
helpers declare typed role dependencies.

Compute the closure before allocating Wasm indices. Emit the resulting catalog
once. Do not emit the complete support library and then perform semantic DCE,
and do not introduce a second reachability or index map beside the catalog.

### Non-goals

- Do not change Lane source semantics or effect-row meaning.
- Do not assume continuations are single-shot unless their exact use proves it.
- Do not specialize nominal storage families merely to remove adapters.
- Do not remove the canonical generic fallback.
- Do not merge Runtime ANF, VM CFG, Physical Program, or Wasm; each retains its
  distinct verified invariant.

## Acceptance Criteria
- [x] Post-effect Core optimization reaches a structural fixed point through one
      worklist and preserves effect-aware evaluation semantics.
- [x] Runtime ANF represents join points, direct callables, and escaping closures
      explicitly, and its verifier rejects first-class use of a join point.
- [x] No direct-only callable allocates a closure, environment, callable adapter,
      or callable-table entry.
- [x] Every remaining closure has an exact first-class escape, and every
      remaining adapter has a structured unequal-ABI reason.
- [x] Complete equal runtime contracts for the same semantic implementation
      share exactly one worker; ABI equality never merges different bodies, and
      identity adaptations emit no worker or bridge.
- [x] Open generic fallbacks remain executable and recursive specialization SCCs
      have a finite canonical demand set.
- [x] The Wasm catalog contains exactly the transitive closure of required
      imports, physical bodies, runtime functions, helpers, shape support, and
      lifecycle functions before index allocation.
- [x] Explore reports zero direct-only materialized closures, zero duplicate
      complete-ABI workers, and zero unreachable emitted runtime/helper roles.
- [x] Example 37 strictly reduces Physical functions or slots and Wasm functions
      or locals from the recorded pre-implementation baseline without using the
      metric values as semantic thresholds.
- [x] JIT and `--no-jit` execution agree, all native tests pass, all valid
      examples pass, and the Basic integration test preserves its expected
      behavior.
- [x] Black-box pipeline and Explore regressions cover observable behavior;
      white-box tests are limited to otherwise unobservable SCC, ABI interning,
      and catalog-closure invariants.
