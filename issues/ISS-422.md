## Description
The optimization document still presents a pre-current-HEAD Basic snapshot and
recommends completing ISS-413 and ISS-414 even though both are closed. The
project needs a current owner-produced account of the expansion from Runtime
ANF through Physical Program to emitted Wasm before another optimization is
chosen.

## Design
Use the committed Explore protocol and current pinned Basic plus a representative
effect-heavy example. Record stable stage, provenance, instruction-category,
function, table, local, representation-bridge, object, callable, ARC, guard,
and helper facts. Attribute expansion to the stage that owns it; distinguish
required semantic work from demonstrated duplication. Update the priority
document with the current evidence and open follow-up work only where a
removable structure is proven.

- [ ] Current HEAD and pinned Basic inputs and commands are recorded.
- [ ] Runtime ANF, VM CFG, Physical, and Wasm scale facts are captured through

- [ ] Stale ISS-413/414 recommendations and obsolete baseline claims are removed.
- [ ] Any demonstrated removable structure has a focused follow-up issue.
- [ ] Native tests and representative execution remain unchanged.
