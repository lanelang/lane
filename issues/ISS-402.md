## Description
Source externs currently name a semantic registry symbol and Basic `println`
passes a Lane String through that registry. Neither contract is a standard
core-Wasm/WASI interface.

## Design
Adopt `extern("module", "field")` with a deliberately small raw core-Wasm
value universe. Certify `wasi_snapshot_preview1` declarations through the
canonical catalog. Implement Basic console output above a compiler-owned narrow
guest-memory interface for borrowed bytes and temporary `ciovec`/`nwritten`
records. Emit the WASI command `_start` lifecycle and canonical `memory` export.

Rich Lane values, closures, layout witnesses, and host objects never cross the
raw extern seam implicitly.

## Acceptance Criteria
- [x] Source externs carry an explicit module and field.
- [x] Unsupported rich or generic extern types receive one source diagnostic.
- [x] WASI imports are certified against the canonical catalog.
- [x] Basic `println` uses `wasi_snapshot_preview1.fd_write` through the narrow
      guest-memory seam.
- [x] Emitted programs export `_start` and canonical `memory` as required.
- [x] Public valid and invalid examples cover raw extern and WASI contracts.

## Close Notes

Closed on 2026-08-28. Source externs now name a core Wasm module and field and
accept only mechanically lowered scalar signatures. WASI Preview 1 declarations
are certified against the shared catalog. Basic `println` builds the guest
`ciovec` record and calls canonical `fd_write`; emitted commands export `_start`
and `memory`. Public examples cover the accepted contract, missing annotations,
rich-value rejection, and WASI signature mismatch.
