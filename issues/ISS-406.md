## Description
Opaque external values are the largest self-contained remnant of the former
multi-target embedding model. They require a host object store, execution-local
generational handles, a second Wasm token table, ownership rollback, runtime
service exports, resource limits, and semantic marshaling. The accepted
WebAssembly-only RFC explicitly replaces Preview 1 resources with integer
descriptors and forbids implicit rich-value extern marshaling.

## Design
Remove Opaque from extern value kinds and reject external nominal value types at
the source extern seam. Delete the Host Object Store, Host SDK projections,
Wasm host-object token bridge, HostObjectNew/Release runtime services, related
resource limits, tests, and the valid example that advertises the removed
capability. Keep external effect identities: they are static Lane effect facts
and do not require a runtime host object representation.

Do not replace Opaque with another handle abstraction. Future Preview 1
resources use explicit integer descriptors; future typed Component Model
resources require a separate design.

## Acceptance Criteria
- [x] External nominal value types are rejected as extern parameters/results.
- [x] No Opaque runtime value, host object handle/store, token table, SDK
      projection, or HostObjectNew/Release service remains.
- [x] Scalar and String legacy extern behavior remains unchanged until ISS-402.
- [x] Native tests, valid examples, and Basic tests pass.

## Close Notes

Closed on 2026-08-28. Removed the generic Opaque value kind, typed host-object
SDK/store, execution-local handle table, Wasm token bridge, object allocation
and release services, resource limit, and their representation-lowering paths.
Runtime Context was deleted with the state it existed to carry. External
nominal value parameters/results now fail at the source extern boundary, while
external effect identities remain valid static facts. The module-object schema
advanced to 23 because its runtime-import value-kind codec changed.

Validation: `moon check --target native`, all 1726 native tests, the complete
examples fixture, and all 12 pinned Basic tests pass.
