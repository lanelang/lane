## Description
Update the Basic repository from Int, S32, and Double to I64, I32, and F64, add the F32 module and offers, and expose the complete compiler-owned builtin surface through ordinary Lane declarations.

## Design
Rename modules, declaration prefixes, offers, conversions, and dependent APIs instead of retaining compatibility shims. Basic remains ordinary Lane code over the closed intrinsic table. `test.sh` is a thin developer check that launches the test entry through the default JIT path; it does not own test enumeration or interpret the test framework's result output. The substantially slower interpreter is validated by Lane's compiler-owned tests instead of duplicating the complete Basic run.

## Acceptance Criteria
- [x] Basic contains coherent `Basic.Data.I64`, `Basic.Data.I32`, `Basic.Data.F64`, and `Basic.Data.F32` modules.
- [x] Arithmetic, equality, comparison, constants, and explicit conversions are exposed through consistently named builtin declarations and offers.
- [x] Every Basic source and test uses the new primitive names; old numeric module and declaration names are removed.
- [x] Basic's test entry can be launched through the default `test.sh` check against the new Lane compiler.
- [x] Test enumeration and result reporting remain owned by Lane source under `test/`, not duplicated in shell parsing.
