## Description
Add aliased qualified imports with syntax such as
`import Basic.Data.List as List`. The alias replaces the complete module path
as the authored qualifier while preserving the imported module's canonical
identity for resolution, fixed surface sugar, interfaces, artifacts, and
linking.

## Design
Treat canonical imported modules and lexical module bindings as separate
concepts. An alias is a single-identifier source binder that points to one
canonical module. Authored qualified access resolves through the local binding;
fixed sugar resolves its canonical provider target. Both paths produce the
same resolved symbols. Do not add List/Tuple-specific alias branches or carry
alias presentation into checked semantic types.
