# ISS-254: Unify LoisVM around ByteSequence

## Metadata
- Type: feature
- Status: open
- Priority: 1
- Labels: loisvm, bytecode, interpreter, ownership, agent
- Assignee: unassigned
- Created: 2026-07-30
- Updated: 2026-07-30
- External ref: ADR-0124

## Description
Replace separate String and Bytes runtime operations and layouts with the shared ByteSequence representation, add S32 execution, UTF-8 validation, and preserve exact ownership and COW behavior in the interpreter.

## Design
Use representation-named ByteSequence instructions, exact-size allocation, checked preflight, and no cached String metadata. Keep semantic String/Bytes separation above lowering.

## Acceptance Criteria
- [ ] Bytecode, VM CFG, verifier, finalizer, disassembler, and interpreter use the accepted S32 and ByteSequence operations.
- [ ] String/Bytes conversions reuse one ARC object and shared updates copy before mutation.
- [ ] UTF-8 validation and String literal-pattern equality execute without dedicated String operations.
- [ ] Focused bytecode and interpreter tests pass.
