## Description
Complete the migration by deleting definition-global runtime-polymorphic
analysis, documenting the phase contracts, and proving that concrete
specialization and symbolic companion forwarding are observationally
equivalent across production execution tiers.

## Design
Use paired fixtures that differ only in whether a concrete call passes through
a generic wrapper. Validate small structured plans and every compiler boundary;
validate runtime behavior through the direct interpreter, Wasm interpreter, and
Wasm JIT. Record deterministic counts of retained definitions and specialized
instances where useful for regression diagnosis.

## Acceptance Criteria
- [x] `collect_runtime_polymorphic_definitions` and its Boolean retention table are deleted.
- [x] Direct and forwarded forms agree for Empty, Io, algebraic, mixed, and higher-kinded companion cases.
- [x] Parameterized external effects recursively rewrite source effect parameters to residual projections.
- [x] Direct, forwarded, mixed algebraic/external, and nested external argument forms elaborate without free source binders.
- [x] Source effect substitutions are absent from runtime layout selection.
- [x] Architecture terminology and ownership rules are documented.
- [x] `moon info && moon fmt` completes with reviewed interface changes.
- [x] `moon test --target native` passes.

substitution and companion association.

mixed, and higher-kinded companion cases through direct and symbolically
