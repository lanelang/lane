## Description
Implement the complete reviewed contract in ADR 0124 across the Lane frontend, semantic IRs, artifacts, LoisVM runtime, backends, tooling, tests, and documentation.

## Design
Treat `S32` and `Char` as distinct semantic primitives sharing `I32 + Trivial`, make String always-valid UTF-8, and unify String and Bytes behind one runtime ByteSequence layout without adding implicit conversions or compiler-recognized library declarations.
