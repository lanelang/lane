# ISS-373: Consolidate compiler IR invariants and fact ownership

## Description
Lane has accumulated compiler representations whose public names imply stronger
phase boundaries than their structures enforce, and derived facts that are
copied or independently reconstructed by multiple packages. The resulting code
must synchronize parallel ASTs, side tables, index formulas, diagnostic
adapters, and observation catalogs even when only one location has enough
semantic context to own the fact.

This epic makes the pipeline a chain of necessary, independently meaningful
representations. Every public IR must state and enforce its invariant, and
every derived fact must have one producer. Transformation time states, display
snapshots, and cached projections do not become public IRs merely because a
debugger or Explore can observe them.

## Design
Retain the representations whose invariants are genuinely different: Syntax,
Resolved Source, Checked Source, Buslane, effect-aware CPS Core, Runtime ANF,
VM CFG, ARC-final VM CFG, physical-slot planning, LoisVM Bytecode, and Wasm.
Do not merge Buslane with VM CFG, ARC-final/physical-slot state, Bytecode, or
Wasm.

Deepen the Modules at the seams between those representations. Source
elaboration, module dependency analysis, effect lowering, Runtime ANF lowering,
execution-root planning, callable-adapter planning, Wasm identity allocation,
and Explore observation each own one coherent result. Consumers receive typed
facts; they do not recover meaning from names, traversal order, raw indices,
type spelling, or structural equality after lowering.

Replace old paths as each owner is established. Do not retain compatibility
fallbacks, parallel producers, public transitional ASTs, or duplicate white-box
tests. Prefer black-box pipeline coverage; use white-box tests only for
otherwise unobservable catalog completeness, canonical keys, and verifier
invariants.

## Acceptance Criteria
- [ ] Every retained public IR documents its invariant, sole construction or
      validation seam, verifier, and consumers in the owning glossary.
- [ ] Source elaboration and module dependency diagnostics each have one
      producer shared by batch compilation and the semantic workspace.
- [ ] Runtime ANF contains only backend-lowerable structure and runtime-relevant
      generic applications.
- [ ] Effect-lowering time states are private implementation details rather
      than public IR seams.
- [ ] Executable initialization, callable-adapter identity, Wasm function/table
      identity, and Explore stage/scale facts each have one producer.
- [ ] Redundant source, module-object, entry, and external type side tables are
      removed, including the required artifact schema migration.
- [ ] ISS-370, ISS-372, and ISS-374 through ISS-382 are closed with their own
      verification evidence and no fallback implementations remain.
- [ ] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`, and
      `moon test --target native` pass after the complete migration.
