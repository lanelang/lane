## Description
Three valid examples disagree between LoisVM's interpreter and the default Wasm
JIT path. `21_functional_programming` traps with an out-of-bounds SIGBUS,
`84_f32_operations` silently computes an incorrect assertion result, and
`96_integer_set_adt` reaches an emitted `unreachable`. All three succeed under
`--no-jit`.

The emitted modules pass `wasm-tools validate`, and Wasmtime executes them
without trapping when Lane runtime imports are stubbed. This establishes a JIT
path defect but does not yet prove whether its owner is Wasmoon, MilkIR, or
Lane's translation and optimization contract. The three symptoms must be
minimized independently before claiming a common cause.

## Design
Build a deterministic differential harness that compiles each source program
once and runs the same linked program through the LoisVM interpreter and Wasm
JIT. Preserve the first divergent artifact, then minimize the responsible
function and compare Wasm translation, MilkIR before and after optimization,
and generated machine-code behavior.

Fix the first owner that produces an invalid semantic transformation. Do not
disable JIT, lower the optimization level, add a runtime fallback, skip an
example, or special-case any source construct. If the defect is upstream,
upgrade to a released fixed dependency or repair the Lane integration contract;
do not carry an unversioned local dependency.

## Acceptance Criteria
- [ ] Each example has a focused regression that compares interpreter and JIT
      behavior through a stable public execution boundary.
- [ ] The first divergent compiler/runtime boundary is identified with a
      minimized artifact and a source-backed explanation.
- [ ] `21_functional_programming`, `84_f32_operations`, and
      `96_integer_set_adt` produce their expected output under both the default
      JIT and `--no-jit`.
- [ ] No JIT disablement, optimization-level downgrade, fallback, fixture skip,
      or example-specific branch is introduced.
- [ ] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`,
      `moon test --target native`, and the complete examples check pass.
