## Description
Callable-flow proves that some final indirect calls have exactly one physical
target, but devirtualization retains `CallValue` when the environment is known
only as `PackedEnvironment`. Current Explore baselines contain 35 such calls in
the pinned Basic test entry and nine in the coroutine scheduler. They still pay
indirect-table dispatch and callable ABI guards even though target selection is
no longer dynamic.

The packed callable itself may remain semantically necessary because it escapes
through aggregate storage or another first-class boundary. The removable fact
is only the call-site target dispatch; this task must not claim that every
corresponding closure or environment can be deleted.

## Design
`CallableFlowAnalysis` remains the sole producer of target and environment
knowledge. Extend VM CFG devirtualization with one explicit representation for
a direct target whose environment is borrowed from a still-live packed callable.
The operation must preserve the packed callable as the environment owner for
the complete call and use the target's verified callable ABI. Physical
finalization and Wasm emission consume this form; they do not rediscover the
target by inspecting callable bits or table entries.

Rewrite only `ExactTarget(target, Packed)` facts with a complete ABI match.
Multiple and unknown targets remain indirect. Do not use call frequency,
function size, source provenance, or a profitability threshold. Function-table
reachability consumes the rewritten direct edge through its existing owner.

## Acceptance Criteria
- [ ] VM CFG represents a direct call that borrows its environment from an
      owned or borrowed packed callable without shortening the owner's lifetime.
- [ ] Callable-flow is the only producer deciding when an exact packed target
      can use that representation.
- [ ] Physical and Wasm lowering consume the direct edge without an indirect
      callable ABI guard or target-table dispatch.
- [ ] Capture-free, local-environment, packed-environment, multiple-target, tail
      call, borrowed-callable, and fatal-unwind cases have focused regressions.
- [ ] The coroutine scheduler removes its nine exact-target packed indirect
      calls and preserves output.
- [ ] The pinned Basic entry removes its 35 exact-target packed indirect calls
      and preserves output.
- [ ] Explore records the resulting direct/indirect, runtime-guard, table, and
      Wasm instruction changes without a heuristic budget.
- [ ] `moon info`, `moon fmt`, strict native check, native tests, Basic tests,
      and valid examples pass.
