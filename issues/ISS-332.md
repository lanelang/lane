# ISS-332: Make the review standard evidence- and boundary-aware

## Description
The review standard says that tests answer whether code works, that every stage
uses the Buslane verifier, and that every package owns a `CONTEXT.md`. Those
absolute statements are neither true nor desirable: tests are evidence rather
than proof, non-Buslane IRs have layer-specific verifiers, and many leaf
packages inherit one coherent subsystem responsibility.

## Design
State the review obligations at their real ownership boundaries. Correctness
claims require evidence, each IR uses its owning verifier, and only an
independently meaningful responsibility boundary requires its own context
document. Leaf packages may inherit the nearest owning context rather than
duplicating prose.

## Acceptance Criteria
- [x] Tests are described as correctness evidence rather than proof.
- [x] Stage verification names the verifier belonging to each IR layer.
- [x] `CONTEXT.md` is required at independent responsibility boundaries, not mechanically for every package.

## Close Notes
The review standard now distinguishes evidence from proof, Buslane verification
from verification of other IR layers, and real subsystem boundaries from leaf
package directories. The standard remains strict without requiring duplicated
documentation or the wrong verifier.
