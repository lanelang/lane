## Description
Establish behavior-preserving tests before replacing the specialization
algorithm. Existing tests cover concrete specialization and symbolic forwarding
separately, but do not fully pin mixed demand, unreachable symbolic uses, or the
equivalence between direct concrete application and generic forwarding.

## Design
Add small complete white-box observations for specialization shape and public
execution examples for observable behavior. Tests must inspect complete stable
structures rather than search debug strings or encode identifier-to-array
storage conventions.

## Acceptance Criteria
- [x] A definition used both symbolically and concretely has a regression test.
- [x] An unreachable symbolic use cannot change a reachable concrete specialization.
- [x] Direct concrete use and generic forwarding have equivalent runtime behavior.
- [x] Higher-kinded companion forwarding remains covered.
- [x] Targeted native tests pass.
