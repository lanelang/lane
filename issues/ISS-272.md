## Description
Lanec has extensive tests, but most are white-box tests and the compiler facade
test package acts as a cross-package integration sink. At review time there
were 888 white-box and 35 black-box test blocks; `compile_wbtest.mbt` alone was
6035 lines and directly exercised analysis, artifact codecs, module compilation,
linking, executable elaboration, and pretty printing.

Coverage was 77.45% for lanec overall, while the persisted artifact binary
boundary was 64.71% and module compilation was 71.81%. Test volume is therefore
not aligned with boundary risk.

## Design
Move tests to the package that owns the behavior. Preserve white-box tests for
unobservable invariants, but convert public compiler, artifact, and link
behavior to black-box contract tests. Split the compiler facade test sink by
semantic owner instead of by arbitrary file length.

Build malformed artifact matrices around tags, truncation, resource limits,
identity references, side tables, and checksums. Measure coverage as a guide to
missing behavior, not as a substitute for explicit acceptance cases.

## Acceptance Criteria
- [ ] Compiler facade behavior has black-box tests independent of internal pipeline imports.
- [ ] Artifact codec and link tests live with their owning packages and cover valid and malformed public inputs.
- [ ] Analysis and presentation tests no longer remain in `compile_wbtest.mbt` solely for historical convenience.
- [ ] White-box tests are retained only where the invariant cannot reasonably be observed through a public API.
- [ ] `compile_wbtest.mbt` no longer requires broad cross-package wbtest dependencies.
- [ ] Artifact-binary and module-compile uncovered failure branches are reviewed and either covered or documented as unreachable invariants.
- [ ] Coverage does not regress from the recorded baseline, and the report records package-level results for compile, artifact, link, typecheck, and analysis.
- [ ] `moon info`, `moon fmt`, focused tests, `moon test --target native`, examples, and `git diff --check` pass.
