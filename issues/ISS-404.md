# ISS-404: Persist raw WebAssembly executables

## Description
Lane still wraps Wasm bytes in a versioned linked-program container whose only
remaining extra payload is the duplicated semantic runtime-import manifest.

## Design
Delete `LinkedProgramArtifact` and its binary schema. The actual WebAssembly
import section is now authoritative, so no semantic manifest is needed to
authenticate transitional host bindings. `lane link` writes raw `.wasm`;
`lane exec` reads, validates, and executes raw `.wasm`. Relocatable module
interfaces and module objects remain target-independent artifacts.

## Acceptance Criteria
- [x] `lane link` writes a standards-valid raw WebAssembly module.
- [x] `lane exec` reads raw WebAssembly bytes without Lane container framing.
- [x] Linked-program schema, codec, inspect output, and active `.lbp` documentation are
      deleted.
- [x] Module interface and object artifact round trips remain unchanged.
- [x] CLI black-box tests cover link then exec through the raw `.wasm` file.
