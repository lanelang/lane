## Description
Implement the globally available pure generic `Array[T]` value described by
`modules/lanec/docs/array-rfc.md`.

The RFC defines the source type constructor, closed polymorphic compiler
intrinsics, representation erasure, runtime object layout, ownership, pure
copy-on-write updates, Basic wrappers, and source-to-Wasm validation contract.

## Design
Treat the accepted RFC as the authoritative design contract. Its 2026-08-28
review aligns the implementation with the Wasm-only pipeline: source and
Buslane own the compiler-built-in type constructor, Runtime ANF owns the closed
runtime Array/evidence projection, the verified Physical Program owns operation
and ownership contracts, and Wasm is the sole runtime implementation.

When resumed, split the work into dependency-ordered child issues following
the RFC implementation sequence. Preserve its central invariants: one
compiler-owned Array type-constructor identity, one authoritative runtime
element-layout source per operation, ordinary first-class generic builtin
behavior, no source-type-based layout guessing, no runtime reflection, and no
Array extension to the host ABI.

## Acceptance Criteria

## Close Notes

- 2026-08-28: ISS-415 through ISS-419 delivered the accepted RFC as five
  dependency-ordered ownership seams: semantic/artifact identity, Runtime ANF,
  verified VMCFG/Physical operations, the sole Wasm runtime, and Basic/tooling.
- 2026-08-28: `Array[T]` is one compiler-owned higher-kinded constructor with
  ordinary first-class generic builtin behavior. Runtime values contain only a
  portable `LayoutId` and erased payloads; no source types, reflection, `Any`,
  host generic ABI, or per-type worker cloning were introduced.
- 2026-08-28: Runtime tests prove exact object sizing, descriptor-directed ARC,
  independently owned `get`, unique and shared `set`, alias preservation,
  zero-length consumption, allocation rollback, bounds checks, and malformed
  companion rejection under both Wasmoon modes.
- 2026-08-28: Final evidence is 1,742 passing native compiler tests, 13 passing
  Basic groups in both interpreter and JIT modes, and the complete valid,
  invalid, separate-compilation, and Explore example fixture gate.
