## Description
Runtime ANF contains generic binders and type applications whose variables no
longer occur after effect information is projected out. In the current
Coroutine Scheduler report, selective CPS contains six type parameters that
appear only once, while Runtime ANF contains seventeen.

Runtime projection preserves `TypeLambda` and `TypeApply`, maps function
effects to `Empty`, and maps every `EffectArgument` to `EffectArgument(Empty)`.
ANF simplification recurses into type lambdas but does not remove the now
vacuous binder and its corresponding application argument. This adds no source
semantics, but it complicates representation planning and obscures which
generic arguments affect runtime ABI.

## Design
Add one binder-identity-aware cleanup at the Runtime ANF boundary. Compute
which type binders occur in runtime-relevant parameter, result, capture,
layout, and witness positions, then remove every vacuous binder together with
the corresponding argument at all applications. The transformation operates
on typed structure and preserves binder order for surviving arguments.

Treat higher-kinded companions and explicit layout witnesses as runtime uses.
Process recursive groups and mutually recursive applications as one verified
unit. Do not infer liveness from rendered text, binder names, effect syntax, or
the number of occurrences, and do not reinterpret `Empty` as unavailable
effect information.

## Acceptance Criteria
- [ ] Runtime projection and cleanup remove every binder that has no
      runtime-relevant use and remove its application argument atomically.
- [ ] Surviving binder and argument order remains definitionally and
      representationally correct across nested `TypeLambda` and `TypeApply`.
- [ ] Higher-kinded companions, layout-constructor witnesses, existential
      evidence, and recursive generic groups are preserved when used.
- [ ] A focused black-box fixture demonstrates that effect-only generic
      parameters disappear from Runtime ANF and later lowering.
- [ ] The Coroutine Scheduler has no projection-created vacuous binder shells;
      Explore records the before/after binder and type-application counts.
- [ ] The effect-aware CPS Core observed before runtime projection is unchanged.
- [ ] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`, and
      `moon test --target native` pass.
