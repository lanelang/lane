## Description
`Basic.Io` needs an intentionally fatal operation. Fatal panic is distinct from
a recoverable `Result`, a handled Lane effect, and an accidental host failure.
It must remain observable in statement position, terminate identically on both
production backends, and not require every embedding to register a magic host
symbol.

The earlier implementation used Basic's nominal empty `Void` as the source
result and derived an execution `Never` ABI from empty enums. That conflated
data inhabitation with control behavior and rejected ordinary legal functions
such as `identity(value : Void) -> Void { value }`.

## Design
Expose one closed compiler intrinsic with the canonical source type:

```lane
pub let panic : (String) -> Basic.Data.Void.Void ! Panic = builtin("%panic")
```

Canonical Void is an ordinary nominal empty result with its ordinary data ABI.
`absurd` performs explicit elimination into the result required by a caller.
The compiler-provided, non-algebraic `Panic` effect owns source-level
observability without claiming that fatal control performs I/O. The verified
intrinsic contract marks the implementation terminal, and the compiler-owned
wrapper's `Fatal(message)` terminator owns the lack of a normal successor and
produces `ExecutionError::Fatal(message)`.

Do not introduce bottom typing, a source or execution `Never`, empty-enum
control inference, no-return call opcodes, contextual panic elaboration, or a
public Runtime Import. `Panic` has no operations, handler, or dictionary and is
not a generic replacement for `Io`. User-defined empty enums remain ordinary
nominal data. Recoverable failure remains ordinary `Result` or
algebraic-effect design and is out of scope.

The Canonical Basic ABI adapter owns all fixed Basic provider resolution and
shape validation at the module-input seam. Resolution freezes identities for
Tuple, List, Void, and structural-derivation providers from the current module
and Reachable Interface Closure. Semantic checking certifies those identities
once. Sugar expansion, intrinsic typing, and derive elaboration consume the
catalog outputs and never repeat provider lookup or shape validation.

## Acceptance Criteria
- [x] The fatal-control RFC defines `panic : (String) -> Void ! Panic` as a compiler intrinsic.
- [x] `Panic` is a compiler-provided non-algebraic effect distinct from `Io`, with no operation, handler, or dictionary.
- [x] Source type, effect observability, and execution termination have distinct owners.
- [x] Direct and first-class panic calls use the ordinary nominal Void result ABI.
- [x] The compiler-owned wrapper ends in verified `Fatal(message)` and creates no Runtime Import.
- [x] No source or execution `Never`, no-return call form, or empty-enum control inference remains.
- [x] Removing the persisted `Never` and no-return call forms advances the linked-program schema to 14, and the decoder rejects schema 13.
- [x] The Void-result migration advances interface/object/linked schemas to 13/20/16; persisting the certified runtime ABI contract subsequently advances the object schema to 21 and rejects 20.
- [x] Interpreter and Wasm executions terminate with the same structured fatal outcome and do not continue after panic.
- [x] Fatal unwinding and owned-value cleanup are covered at both production backend boundaries.
- [x] Wrong builtin annotations use the ordinary canonical-signature diagnostic.
- [x] Panic in a Unit context remains observable through explicit `absurd[Unit]` elimination.
- [x] Recoverable host failures remain outside this issue and no second implicit failure channel is introduced.
- [x] Basic exports `panic : (String) -> Void ! Panic = builtin("%panic")`.
- [x] One frozen Canonical Basic ABI identity catalog resolves Tuple, List, Void, and derive providers from each module input closure.
- [x] One semantic adapter certifies Tuple, List, Void, and derive shapes; resolver and typechecker consumers do not rediscover providers.
- [x] Resolver diagnostics and linker-time Void identity/shape certification are owned by the Canonical Basic ABI adapter; downstream phases consume its structured errors and certified runtime contract.
- [x] Malformed Tuple and List providers produce one Canonical Basic ABI diagnostic, and indirectly reachable providers resolve through the module input closure.
- [x] A black-box Lane command regression invokes shipped `Basic.Io.panic` and proves that execution does not continue.
- [x] `moon info`, `moon fmt`, `moon test --target native`, and the integration gate pass.
