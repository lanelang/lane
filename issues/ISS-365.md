# ISS-365: Eliminate implicit CPS binder families

## Metadata
- Type: bug
- Status: closed
- Priority: 1
- Labels: area/lanec, area/core-opt, area/effect-lowering, effects, architecture, compiler-defect, tests, agent
- Assignee: codex

## Description
Selective CPS returned a Buslane program and a parallel array relating each
source effect binder to its higher-kinded companion and residual binder. The
generic Core optimizer could freshen nested type binders while the array kept
old identities.

The deeper defect was the representation itself: nominal and existential
effect binders remained as source identities after callable binders had been
expanded. The array attempted to repair a CPS program that was not closed under
its own binders.

## Design
Eliminate the implicit family instead of preserving it in a stronger sidecar.
Selective CPS expands every effect binder and application into the explicit
ordered companion/residual pair described by ADR-0137. The source binder does
not survive in CPS Core. Ordinary alpha-renaming then transforms all remaining
facts through the IR itself.

Executable and LoisVM interfaces accept no companion registry. They must not
reconstruct source effects from binder names, kinds, metadata order, runtime
layouts, or effect syntax.

## Acceptance Criteria
- [x] Callable, nominal, constructor-existential, and pattern binders use one
      explicit companion/residual elaboration.
- [x] Higher-kinded parameter kinds and applications expand effect positions by
      the same rule.
- [x] Executable and LoisVM lowering contain no source/companion registry or
      reverse source-effect substitution.
- [x] Nested polymorphic companion clones remain closed under ordinary Core
      alpha-renaming.
- [x] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`, and
      `moon test --target native` pass.

## Notes
- 2026-08-12: Independent CPS and erasure audits found that
  `InlineCloneContext` freshens binders without updating the
  `EffectCompanionBinding` sidecar. This is a latent invalid-state boundary even
  after the runtime metadata split-brain is fixed.
- 2026-08-12: Deeper audit rejected a phase-owned triple registry. A source
  binder paired with multiple cloned companion/residual scopes has no
  unambiguous inverse. ADR-0137 instead makes the established two facts
  explicit at nominal and existential scopes and deletes the sidecar.

## Close Notes

Implemented ADR-0137 rather than strengthening the invalid sidecar. Selective
CPS now expands effect positions in callable binders, nominal declarations,
constructor existentials, pattern binders, and higher-kinded parameter kinds.
Every application supplies the explicit companion and residual arguments.

Removed `EffectCompanionBinding` and `SelectiveCpsRewrite` from the public CPS
interface, removed `ExecutableProgram.effect_companions`, and deleted the two
LoisVM substitution paths that recovered a source effect from companion
identity. Ordinary Core alpha-renaming now sees every surviving binder.

Focused CPS and LoisVM tests cover higher-kinded effect applications and
effect-indexed existential evidence. Backend conformance passed 44/44 and the
full native suite passed 1679/1679.
