## Description
`WasmFunctionCatalog` owns identities and ordering but still declares the full
runtime/helper role lists and every shape destructor before emission. This
forces JIT compilation of support that the final Physical Program may not
reference.

## Design
Make the catalog own a typed dependency graph among physical operations,
runtime roles, helper roles, shape support, lifecycle and exports. Starting
from entry, designated runtime-service exports, the already-reachable Physical
Program, callable-table entries, global lifecycle and persisted layout recipes,
compute the transitive closure before allocating function indices or table
slots. Object shapes contribute support only through a retained layout recipe;
their mere presence in the metadata array is not a root. Emit the catalog once.

Do not emit all support and run semantic DCE afterward. Do not introduce a
second reachability/index map outside the catalog.

## Acceptance Criteria
- [x] Runtime/helper/shape dependencies are typed and owned by the catalog.
- [x] Function indices and table slots are allocated only after closure.
- [x] Every emitted support role is transitively reachable from a declared root.
- [x] Omitting any required dependency is rejected before Wasm body emission.
- [x] Explore reports zero unreachable emitted support roles.
- [x] Small scalar programs retain designated runtime-service exports but
      exclude unrelated byte-sequence algorithms, host-object destruction and
      shape destructors.
- [x] Native tests, Wasm validation, JIT/`--no-jit`, valid examples and Basic
      tests pass.

## Close Notes

- `WasmFunctionCatalog` now computes a typed root/dependency closure before it
  allocates any function index or table slot. Validation proves that the
  retained set is the exact minimal closure and rejects missing dependencies
  before static-image or function-body emission.
- Runtime and helper emitters consume only catalog-proven handles; eager
  lookups and the `DestroyHostObject` fallback were removed. Layout recipes,
  rather than unreferenced object-shape metadata, own shape helper roots.
- The public provenance regression shrank from 29 to 15 total Wasm functions;
  the Explore scalar regression shrank from 27 to 7 definitions. Example 37
  emits 100 Wasm definitions instead of the 110 recorded after ISS-395 and
  reports `unreachableWasmSupportRoleCount: 0`.
- Verified with `moon info`, `moon fmt`, strict native checking, 1732/1732
  native tests, the full examples gate, Example 37 under JIT and `--no-jit`,
  and Basic 12/12 under JIT and `--no-jit`.
