## Description
Carry `Array[T]` and polymorphic intrinsic evidence through the closed Runtime
ANF boundary without retaining source type syntax or inventing an Array-only
generic call model.

## Design
Project an applied Array type to one explicit runtime Array representation with
its element `RuntimeArgument`. Project intrinsic `Forall` and evidence
application through the same Runtime ANF forms used by ordinary generic
callables. Extend Runtime ANF verification, equality, substitution, pretty
printing, traversal, and simplification around that one representation fact.

## Acceptance Criteria
- [ ] Runtime ANF represents Array values with one element runtime argument and
      natural reference layout.
- [ ] Generic intrinsic evidence applications survive direct and first-class
      source uses through verified Runtime ANF.
- [ ] Runtime ANF verifier rejects missing, ill-kinded, or free evidence.
- [ ] No Buslane source type, nominal placeholder, or Array-only call syntax
      crosses the Runtime ANF boundary.
- [ ] Focused public compiler tests cover exported/imported and indirect Array
      intrinsic values.
