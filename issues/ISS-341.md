## Description
`Basic.Trait.Table` contains unresolved `from_list` and `to_list` placeholders
without signatures, laws, or consumers. The only implementation is `AList`,
no code consumes the `Table` dictionary, and `Basic.Eff.Table` is empty.

The missing semantics matter. `AList.set` prepends without removing older
bindings, `get` returns the first match, and `del` removes every match. A
generic list conversion therefore cannot be added responsibly without
defining duplicate-key precedence, iteration order, stability, and round-trip
laws. Requiring ordered `List` conversion in every table dictionary would also
overconstrain future unordered implementations.

## Design
Do not add `from_list` or `to_list` fields merely to satisfy the placeholders.
Remove the speculative comments. Audit whether the current `Table` dictionary,
its exposed `key_equal_impl` field, and the empty effect module have a real
public consumer; remove dead abstractions in a Basic-owned change if they do
not.

If a real generic construction consumer appears, implement `from_list` as an
ordinary function derived from `empty` and `set` after specifying duplicate
precedence. If a real traversal consumer appears, introduce a separate
entries/fold capability with explicit order guarantees rather than expanding
the minimum lookup/update dictionary.

## Acceptance Criteria
- [x] The unresolved `from_list` and `to_list` placeholders are removed from Basic.
- [x] No conversion field is added without a concrete consumer and documented duplicate-key, ordering, and round-trip semantics.
- [x] The `Table` dictionary, `key_equal_impl`, its `AList` implementation, and `Basic.Eff.Table` are audited for real consumers.
- [x] Dead table abstractions are removed, or retained declarations receive a concise responsibility and law description.
- [x] Any retained or newly introduced observable table behavior is covered through public Basic APIs rather than private structure inspection.
- [x] Basic's check and integration suite pass with the intended public API change documented.
