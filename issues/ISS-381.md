## Description
The source semantic type of an executable entry or external value is stored in
Buslane Metadata and copied into `BuslaneEntry`, `BuslaneRuntimeImport`, and
the builtin intrinsic contract. Link validation must compare the copies;
remapping, artifacts, fingerprints, inspection, executable admission, and
LoisVM planning must all propagate them independently. A future type field can
therefore drift even though the referenced ValueId already has one authoritative
type declaration.

Runtime Import host signatures are a different fact and must remain explicit:
they describe the erased host ABI, not the Lane source type.

## Design
Make `MetadataRegistry.value_info(value).type_` the sole source semantic type.
Entry descriptors retain module/name/ValueId. Runtime Import descriptors retain
ValueId, symbol, and host signature. Builtin descriptors retain ValueId and the
canonical certified intrinsic identity/classification. Consumers receive the
owning metadata explicitly and query the type through one phase-owned adapter.

Remove copied types from module objects and persisted artifacts, update
fingerprints and inspection, and bump the affected artifact schema. Reject old
schemas normally; do not synthesize missing types, guess from host signatures,
or keep a legacy fallback reader.

## Acceptance Criteria
- [x] Entry, Runtime Import, and builtin descriptors contain no copy of their
      referenced value's source semantic type.
- [x] All source type consumers query the one owning Metadata Registry through
      a typed adapter and preserve normalization failures structurally.
- [x] Runtime Import host signatures remain explicit and are validated against
      the source type at their one certification seam.
- [x] Link validation no longer compares duplicate source type producers.
- [x] Remapping maps the ValueId and Metadata exactly once instead of remapping
      side-table type copies.
- [x] Module object encoding, decoding, fingerprints, inspection, and schema
      version reflect removal of the persisted copies and reject the old schema.
- [x] Black-box artifact round-trip/link tests and executable entry/runtime
      import tests cover the new contract.
- [x] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`, and
      `moon test --target native` pass.

  descriptors, along with the redundant intrinsic contract wrappers. Buslane

  entry type queries instead of copying metadata into each entry view.

  retain their typed cause until the link diagnostic rendering boundary.
