## Description
Structural callable adaptation and closed representation workers now use
complete contracts locally, but the executable pipeline does not yet prove the
ISS-392 invariant that every definitionally equal complete runtime contract for
one semantic implementation shares one worker while every unequal first-class
conversion has one explicit reason.

## Design
After Runtime ANF owns callable disposition, intern complete callable,
representation-worker and adapter-worker contracts inside Physical Lowering.
The Physical Callable ABI Graph remains the owner of invocation compatibility;
closure environment is an implementation fact and must not be folded into that
graph. Equal contracts for the same semantic implementation share one worker,
identity adaptations disappear, direct conversions fuse into calls, and an
escaping source/target/alignment contract materializes at most one structural
adapter. Preserve the generic fallback and finite recursive specialization
demand set.

The callable contract includes every evidence, value parameter and result
boundary, including representation, cleanup, semantic runtime category,
object/callable shape and witness provenance. A representation-worker contract
also includes its semantic source implementation and closed Runtime ANF
arguments because uniform nominal storage can hide nested differences from the
outer callable boundary. Source syntax, names, widths or layout IDs alone are
not keys.

## Acceptance Criteria
- [x] Equal complete runtime contracts for one semantic implementation share
      one worker; equal ABIs never merge different function bodies.
- [x] Identity adaptations emit no bridge, environment or worker.
- [x] Each remaining escaping adapter has one structured unequal-contract reason.
- [x] Direct conversions are fused without first-class materialization.
- [x] Open generic fallbacks remain executable and recursive demand is finite.
- [x] Explore reports zero duplicate complete-ABI workers.
- [x] Native tests, valid examples and Basic tests pass under JIT and `--no-jit`.
