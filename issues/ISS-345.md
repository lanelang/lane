## Description
Parameter inlay hints classify a checked call argument as authored or synthetic
by comparing its source offsets with the enclosing call span. Pipeline
desugaring is encoded as a special positional coincidence: the prepended
synthetic argument starts where the expanded call starts. This reconstructs
semantic provenance from spelling and can break when source spans, desugaring,
or new call forms change.

## Design
Attach authored-versus-synthetic provenance when call arguments are constructed
or desugared, preserve it through checked call representation, and let semantic
navigation consume that fact directly. Source spans remain presentation data;
they must not decide whether an argument was written by the user.

## Acceptance Criteria
- [x] Checked call arguments or an adjacent stable fact carry explicit authored
      or synthetic provenance.
- [x] Pipeline, operator, ordinary, labeled, and inserted `auto` arguments set
      provenance at their owning construction boundary.
- [x] Semantic navigation contains no offset comparison or call-form special
      case for determining authored arguments.
- [x] Black-box inlay-hint tests cover nested pipeline calls, implicit offers,
      ordinary calls, and operator syntax.
- [x] `moon info`, `moon fmt`, `moon test --target native`, LSP integration, and
      `git diff --check` pass.

## Close Notes

`CallArgumentProvenance` is now a syntax-domain fact carried by desugared and
checked call arguments. Ordinary and labeled arguments become `Authored` at
source desugaring; pipeline operands, operator operands, and inserted contextual
offers become `Synthetic` at their respective construction boundaries. Named
auto arguments preserve their authored provenance when reordered into the
positional checked call ABI.

Semantic navigation now reads the checked fact directly. It no longer compares
argument offsets with the enclosing call span or encodes the pipeline prepend
position as evidence of authorship. Public Semantic Workspace regressions cover
ordinary imported calls, nested pipeline calls, implicit offers, and source
operator syntax.
