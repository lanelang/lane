# ISS-255: Implement Wasm and host UTF-8 parity

## Description
Implement the accepted S32, ByteSequence, UTF-8, and host String contracts in the Wasm backend and runtime import boundary.

## Design
Match interpreter semantics for all valid inputs. Host inputs are borrowed pointer-length UTF-8 views; host outputs are copied and validated, with invalid UTF-8 treated as a fatal binding violation.

## Acceptance Criteria
- [x] Wasm executes all S32 and ByteSequence operations with interpreter-equivalent valid-input results.
- [x] Host String input supports embedded NUL and temporary borrowing.
- [x] Valid host String output round-trips and invalid UTF-8 fails fatally without replacement.
- [x] Focused Wasm and host tests pass.
