## Description
Handler elaboration, monadic transformation, selective CPS rewriting, and
open-context resolution currently expose successive time states of one open
effect-lowering AST as public stage values. The same `Program` type permits all
ordinary and transitional nodes, while each pass relies on a different subset
being absent. This makes implementation states look like independent IR seams
and requires public model, pretty, verifier, declaration traversal, observer,
and white-box surfaces for a representation with only one pipeline consumer.

## Design
Expose one deep Effect Lowering interface from verified effect-aware Buslane to
verified effect-aware CPS Core. Keep internal passes only where they clarify the
implementation, but make their transitional AST and synthesis helpers private.
Debugging and Explore receive structured rendered observations or metrics from
the owning Module rather than raw constructible intermediate programs.

Progressively fuse transformations where an intermediate tree has no distinct
consumer or independently useful invariant. Do not add four nominal wrappers
around the same open AST merely to encode time. CPS Core remains ordinary
verified Buslane with authoritative residual-effect semantics.

## Acceptance Criteria
- [x] The public Effect Lowering interface accepts verified Buslane and returns
      verified CPS Core without exposing transitional AST constructors.
- [x] Handler, monadic, selective-CPS, and open-context observations remain
      available as owner-produced snapshots without becoming public IRs.
- [x] Each retained internal representation has an explicit invariant checked
      at its actual internal seam.
- [x] Public pretty, verifier, declaration-walker, and synthesis surface that
      existed only for external access to time states is deleted.
- [x] No effect-lowering consumer outside the owning Module pattern-matches the
      transitional AST.
- [x] Existing effect-handler, generic companion, nested relay, and real
      example 37 regressions pass through the new deep interface.
- [x] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`, and
      `moon test --target native` pass.
