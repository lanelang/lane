## Description
Implement `S32` as a complete primitive from source syntax and expected-type-directed literals through Buslane, artifacts, VM CFG, LoisVM bytecode, interpreter, and Wasm.

## Design
Keep S32 definitionally distinct from Int and Byte while using `I32 + Trivial`. Use one signed-32-bit operation family and explicit S32/Int width conversions. Char and Unicode literals remain in ISS-252.

## Acceptance Criteria
- [x] Types, type syntax, resolve, checked AST, Buslane, artifacts, and analysis represent S32 structurally.
- [x] S32 literal expressions and patterns cover both signed bounds and reject out-of-range values.
- [x] S32 arithmetic and S32/Int conversion execute equivalently in the interpreter and Wasm.
- [x] Focused frontend, semantic, codec, interpreter, and Wasm tests pass.
