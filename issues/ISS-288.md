## Description
Effect lowering runs five stages. The two endpoints are Buslane programs; the
three in between carry `lanec`'s extended `Expr`, which adds `Bind`, `Invoke`,
`Install`, and `OpenContext`. Before this issue, the Buslane verifier could not
read those, so nothing type-checked them.

| stage | representation | checked by |
| --- | --- | --- |
| effect-lowering input | Buslane | `verify_program`, since ISS-284 |
| handlers-elaborated | extended | `effect_lowering_core.verify_program` |
| monadic-transformed | extended | `effect_lowering_core.verify_program` |
| selective-CPS | extended | type checker + `validate_mon_trans_output` |
| open-contexts-resolved | extended | type checker + phase validator |
| monadic-lifted | Buslane | `buslane.verify_program`, since ISS-284 |

`validate_mon_trans_output` remains a phase validator, not a type checker. It
walks for residual `Invoke`, `Install`, `Bind`, concrete `OpenContext`,
algebraic latent effects, and algebraic effect parameters or arguments. It never
compares a type against the type a position requires, which is the class of
defect ISS-283 and ISS-284 were both about.

It is insufficient as a type boundary on its own: for example,
`validate_mon_trans_expr` does not inspect a match alternative's
`type_binders`. The shared type checker now owns that responsibility instead of
adding another phase-specific structural walk.

## Design
Reuse the Buslane verifier for the extended IR rather than writing a second type
checker. Reify the extended forms as their typed Buslane semantics: an `Invoke`
is a `Perform`, an `Install` is a `Handle`, and a `Bind` is a function call.
`OpenContext` checks its effect annotations in the lexical type scope and
requires the source contexts to occur in the target, while leaving its body
unchanged.

A shared checker also removes the drift between `types_definitionally_equal` in
one checker and hand-written structural walks in the other.

## Close Notes
The compiler now verifies each extended-IR result before publishing its observer
stage. The checker snapshots metadata, preserves ordinary expressions, and
reifies `Invoke`, `Install`, and `Bind` into the corresponding Buslane typing
forms. `OpenContext` validates both effect annotations in their lexical type
scope and rejects missing target contexts. Phase-specific residual-form
validation remains separate from type checking.

Regression tests cover payload, computation/continuation, final-clause,
alternative-binder, and open-context failures. A boundary test also proves that
an invalid extended program retains its producer stage and is rejected before
observation.
