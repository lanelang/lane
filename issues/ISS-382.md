## Description
Runtime ANF is nominally the closed backend-lowerable IR, but it still stores a
projected Buslane `MetadataRegistry`, Buslane `Type`, `GenericArgument`,
`TypeLambda`, and `TypeApply`. LoisVM lowering consequently repeats type
normalization, substitution, kind lookup, generic-binder liveness, and runtime
representation classification after the runtime projection seam.

The compiler therefore carries source-level type computation into a phase that
should contain only execution-relevant representation facts. Vacuous generic
cleanup and projection scale accounting compensate for this leaked model rather
than establishing a genuinely independent Runtime ANF invariant.

## Design
Make Runtime ANF own a minimal runtime type and evidence model. Preserve stable
nominal declaration identities only where execution needs them, but project
Buslane effects, kinds, forall/type-lambda syntax, and generic arguments exactly
once while constructing Runtime ANF.

Runtime values distinguish unit, scalar, byte-sequence, opaque reference, data
family, callable, and erased representations. Runtime-polymorphic functions
bind explicit layout or layout-constructor evidence; applications carry only
the corresponding evidence expressions. Data construction and matching carry
the already projected runtime facts needed for object shape and field lowering.

LoisVM lowering consumes this model directly. It must not normalize Buslane
types, inspect Buslane kinds, rebuild type substitutions, or recover layout
evidence from source type syntax. Projection observations are returned beside
the program when requested and are not stored as an invariant field of Runtime
ANF.

## Acceptance Criteria
- [x] `AnfProgram` contains no `MetadataRegistry`, Buslane `Type`, Buslane
      `Effect`, `GenericArgument`, `TypeLambda`, or source-level `TypeApply`.
- [x] Runtime ANF has explicit runtime value types, callable types, evidence
      parameters, evidence applications, data families, and constructor facts.
- [x] The CPS-Core-to-Runtime-ANF seam is the sole producer of those facts and
      rejects residual effect operations or malformed applications.
- [x] LoisVM lowering consumes Runtime ANF facts without Buslane type
      normalization, kind lookup, or generic substitution.
- [x] Callable adaptation and erased value conversion operate on the runtime
      model and preserve higher-kinded layout-constructor forwarding.
- [x] Explore derives Runtime ANF scale from the runtime IR rather than storing
      source/runtime projection counters in `AnfProgram`.
- [x] Existing public compiler, interpreter, JIT, generic data, existential,
      external type, and callable-adapter regressions remain correct.
- [x] Explore and the Coroutine Scheduler regression record the new runtime
      structure. Two additional adapter workers are intentionally retained
      because erased callable values now always cross the canonical erased ABI;
      bypassing it was unsound for existential reopening.
- [x] `moon info`, `moon fmt`, `moon check --target native --warn-list +73`, and
      `moon test --target native` pass.

## Close Notes

Runtime ANF now owns a compact representation vocabulary: runtime scalar and
nominal categories, callable and erased value contracts, explicit evidence
binders/applications, data-family metadata, and a runtime type-expression
catalog. The old projected Buslane metadata, source generic arguments, effect
rows, type lambdas, and resident projection-scale counters were removed from
the IR. LoisVM substitution, callable adaptation, layout evidence, match/data
lowering, representation specialization, and slot classification now consume
only this runtime model.

The migration exposed and fixed three independent boundary defects. Recursive
runtime substitutions now preserve one-step substitution rather than expanding
`T -> Box[T]` indefinitely. Unsaturated nominal constructors are eta-expanded
when projected as higher-kinded arguments. Erased callable values always use
the canonical erased-callable ABI, so reopening an existential cannot call a
concrete function with an incompatible result slot.

The obsolete projection-scale implementation and white-box tests that copied
the deleted Buslane-facing lowering structures were removed. Compact
Runtime-ANF-native white-box tests retain the otherwise unobservable adapter
recipe and substitution invariants. New black-box tests cover runtime
representation equality, higher-kinded nominal eta expansion, the real
Coroutine Scheduler fixture, and existing existential callable execution
across the interpreter and Wasm backends.

Verified with `moon info`, `moon fmt`,
`moon check --target native --warn-list +73`, and
`moon test --target native` (1740/1740).
