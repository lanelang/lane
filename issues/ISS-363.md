## Description
The canonical generic ABI correctly carries values through erased and
higher-kinded evidence boundaries, but a closed direct application may retain
avoidable erase/unerase operations. This issue owns representation workers for
such closed definition/application boundaries. Whole-image callable flow is a
different VM CFG fact owned by ISS-369.

The previous implementation made a persistent Callable Instance Plan and
whole-program representation solution prerequisites for lowering. That design
is superseded by ADR-0138 and must not be restored.

## Design
This issue is an optional program optimization after ISS-390 establishes
independently correct generic lowering.

Inspect direct Runtime ANF evidence applications of top-level generic
definitions. A definition is eligible only when every observed direct evidence
application is closed; a self-recursive application that forwards the same
evidence parameters is stable. For each closed `(generic definition, canonical
runtime ABI)` key, create at most one concrete worker and rewrite actual calls.
The candidates, substitutions, worker interning, and recursion ancestry remain
private to Physical Lowering.

Open, indirect, incompatible, unsupported, or recursively expanding uses stay
generic. Recursive calls may reuse a stable existing key; no global proof is
required to lower the generic program. Higher-kinded companions keep explicit
layout-constructor evidence unless a complete closed worker removes the
corresponding generic boundary.

Do not specialize nominal storage families. Values crossing generic nominal
storage keep its declaration-owned erased schema. Closed non-escaping
aggregates may be scalar-replaced by a separate local rewrite.

Aliases, parameters/results, captures, constructor fields, immutable globals,
and other first-class callable paths are deliberately not rediscovered here.
VM CFG callable-flow retains that physical responsibility: classify final
targets, devirtualize singleton target sets, and remove environments when the
whole-image fact proves the ABI rewrite coherent. It does not discover
representation workers.

## Close Notes
Physical Lowering now interns one `RepresentationWorker` for each closed
`(source function, canonical callable ABI)` key. Two calls using the same key
share a worker; distinct Bool and I64 keys produce two workers. Disabling the
rewrite preserves the generic witness-passing implementation and the same
observable result, while enabling it removes the focused fixture's
`ConstLayout`, erase, and unerase bridge operations. Expanding recursive
applications remain on the finite generic implementation.

The real Coroutine Scheduler remains at 60 physical functions and 413 slots.
Representation specialization intentionally leaves its uniform generic nominal
storage unchanged. Of the 21 adapter functions, 20 still escape as first-class
closures; the one direct-only adapter is tracked by ISS-369's VM CFG
callable-flow cleanup. JIT and `--no-jit` both print `1112211322`.
