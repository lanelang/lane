## Description
Update the Basic repository from Int, S32, and Double to I64, I32, and F64, add the F32 module and offers, and expose the complete compiler-owned builtin surface through ordinary Lane declarations.

## Design
Rename modules, declaration prefixes, offers, conversions, and dependent APIs instead of retaining compatibility shims. Basic remains ordinary Lane code over the closed intrinsic table. Its routine library gate uses the default JIT path; the substantially slower interpreter is validated by Lane's compiler-owned tests instead of duplicating the complete Basic run.

## Acceptance Criteria
- [x] Basic contains coherent `Basic.Data.I64`, `Basic.Data.I32`, `Basic.Data.F64`, and `Basic.Data.F32` modules.
- [x] Arithmetic, equality, comparison, constants, and explicit conversions are exposed through consistently named builtin declarations and offers.
- [x] Every Basic source and test uses the new primitive names; old numeric module and declaration names are removed.
- [x] Basic check and its complete default execution gate pass against the new Lane compiler.
- [x] The gate proves the complete expected test set ran, rather than accepting any self-consistent partial summary.
